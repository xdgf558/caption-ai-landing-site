## 本地行为覆盖

新增的套装 UI 用例在 1440px 和 390px 分别执行：模拟未拥有账号 -> 25 点确认 -> 只发送 productId/idempotencyKey -> 余额 100 到 75 -> 猫町/小家/装修选择四项 -> 三个素材全部加载 -> 刷新保持 -> 模拟服务器撤销并返还余额 -> 刷新回免费选项、无付费装饰。

撤销响应由浏览器夹具提供，不冒充真实 Admin 冲正；真正原子返还、幂等和账本仍由既有 storage/API/Admin 测试覆盖。新增四语手机测试核对适用范围、交付限制、规则/客服链接和弹窗无横向溢出。新增 503 测试验证未知结果提示与同键重试。

验证结果：`npm test` 通过；`npm run test:browser` 的 27 项 Chromium 用例通过（商城 18 项，新增 7 项）；`npm run build` 通过（143 页、111 条静态 sitemap、4 个本地化 404）；`git diff --check` 通过。另用本地 Astro 页面核对四语产品页的 1440px/390px 图像加载、积分链接和无横向溢出，并检查截图。

浏览器截图保存在忽略提交的 `test-results/`；商品主图是唯一提交的截图派生资源，42,022 字节。Safari/WebKit 和生产支付未验收。
