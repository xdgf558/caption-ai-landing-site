# R1 第二批：隔离个人清理与本机账号回收

新增 [隔离执行内核与验证说明](../../../scripts/isolated-lifecycle/README.md)。没有改变 policy-draft.json 的 approved/executionEnabled，也没有生产迁移、部署、支付配置或完整销户启用。

本批将已确认冻结账号的凭据和明确归属个人资料清理推进到可恢复、可验证阶段。评论匿名保留所需的 nullable 迁移仅存在于合成数据库；网站评论读取兼容匿名作者。个人阶段成功不等于财务/外部平台/备份清理完成，任务保持 attention_required。

iOS 配套增加“清理其他账号的本机资料”，与封面缓存清理分开。用户确认后只删除已同步且无待发送操作的非当前账号文件；游客、正在同步、损坏、不明文件和符号链接保持原样。服务器账号不受影响。

同步回执新增无损紧凑编码、兼容读取和隔离回滚演练；活跃账号 ID、摘要及墓碑继续保留，未启用自动压缩。

仍未完成：突破现有条数上限或安全淘汰防重放记录的 generation 协议、财务及软关联保留策略、恢复旧备份后的防复活、完整销户最终完成、真实 HTTPS/AASA 和实体机验收。不能据此将 R1 或 v1.0 上架验收标记完成。

本机验证：D1 生命周期 9/9、回执编码 2/2、资料库 18/18、认证 29/29、销户审计 11/11，评论回归通过。Astro 153 页验证构建通过（ALLOW_EMPTY_SERIAL_CONTENT=1，不是生产包）。源码哈希见 [本机证据](R1-local-evidence.json)。尚无本分支远端 CI 结果。
