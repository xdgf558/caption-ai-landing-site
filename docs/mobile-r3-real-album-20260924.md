# R3 真实专辑隔离副本（2026-09-24）

用户批准将已发布的真实歌曲接入测试 App。本次仅复制《晚一点告白》7 首歌曲到既有独立 HTTPS 测试环境，不切换生产原生服务，不导入生产账号，不修改生产数据、开关、支付或订阅。

## 数据和边界

- 唯一目标：`station-cat-music-r2-catalog`（`19595ea0-7359-4ab3-b168-d82247edefa5`）及私有桶 `station-cat-music-r2-audio`。
- API 来源：`https://station-cat-music-r2.yehao1105.workers.dev`。
- 专辑 `wydgb`，版本 5，依次为无人接听、假装顺路、回忆、城市另一端、差一句喜欢、把那年还给风、再走一站。
- 源站这 7 首歌均为免费完整收听，测试副本保留相同权限、音频版本和时间轴歌词。不把真实免费歌曲改为 VIP；原合成免费/VIP 曲目及合成专辑保留用于边界测试。
- 推荐主曲为《把那年还给风》，真实专辑排在合成专辑之前。推荐同时保留合成免费曲目，便于既有实机探针继续定位。
- 读取源站已发布版本；不复制未发布草稿。7 份 MP3 和 7 份 LRC 与源记录的长度、SHA-256 一致。
- 8 张封面采用网站现有的 display JPEG（约 72–146 KB），以新资产 ID 写入独立桶；不改生产原图，不放宽 iOS 2 MiB 图片限制。测试环境无 ASSETS 绑定，直接引用超大生产 PNG 会被客户端拒绝，故将小封面作为独立副本资产。
- 共 22 个对象，46,775,267 字节。媒体仍经原有授权和 Range 接口传输，未开放 R2 公共桶或原始音频地址。

## 导入及验证

导入前已导出目标音乐库到忽略目录 `.generated/r3-real/private/test-catalog-before.sql`。原始元数据、音频、备份、SQL、Wrangler 日志均留在忽略的私密目录，不提交仓库。账户库未导入、未备份生产账号。

`scripts/prepare-mobile-r3-real.mjs` 只离线生成 SQL，不发网络请求。它校验目标配置、源专辑身份、22 个对象的字节及实际 MP3/JPEG/LRC 结构；封面变化后重新计算技术指纹，在测试环境以当前时间发布副本，保留首次发布时间。通过目标库备份进行本机事务预演、外键检查、旧合成记录逐字段比较，并确认重复导入失败。导入 SQL 使用曲库及推荐版本守卫；先上传资产，再导入目标 D1。

本次专辑导入阶段实际远端只写独立 R2 和 MUSIC_DB；该阶段没有部署 Worker 或网站包。后续离线许可及封面缓存的独立测试 Worker 部署另见 [R3 离线与缓存记录](mobile-r3-offline-artwork.md)。
