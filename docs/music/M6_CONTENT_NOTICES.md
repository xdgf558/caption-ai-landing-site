# M6-03 内容与四语收听说明

本切片基于已合并 #156，补齐音乐页面中的收听范围、支持与既有退款说明。只交付实现与合同；具体作品、设备反馈、HTTP 响应、部署版本、备份与 session 材料保存在仓库外，不附带 PR。

## 内容核对

继续执行 [OPTIONAL_SOURCE_MATERIALS](OPTIONAL_SOURCE_MATERIALS.md)：来源、套餐与凭证均可选。无记录或 pending 不阻塞，不生成 approved；已填写的 blocked 结论仍阻止技术核对和发布。已有凭证不删、不补写推测内容。

逐个待发布版本确认完整曲实际试听、独立试听已听且对应源区间；有封面时查看封面。曲目或素材版本发生变化，重新核对。技术核对和已发布状态不是正式发布授权；隔离预发的内容许可不扩展到生产。无歌词、无封面应如实展示，不把装饰唱片当成真实作品封面。

执行核对只读现有管理接口；本切片不上传、不修改来源结论、不重写技术审核、不发布或下架作品。具体核对结果只保存在本机，任务完成不代表所有未来作品通过。

## 四语告知

`music-notices.js` 提供简中、繁中、英文和日文一致的范围：

- 免费完整收听、VIP/抢先与独立试听的区别；试听结束停止。
- 抢先期后的状态按曲目设定；专辑、收藏或分享不授予资格。
- 沿用全站 VIP，价格和期限由原会员中心显示，不新增套餐、单曲扣点或兑换。
- 会员到期、登出或资格撤销停止受保护完整播放；恢复资格不自动续播。
- 在线收听不包含音频下载、离线、转授权或商用许可；分享卡片不扩大范围，封面与已发布歌词仍为公开展示素材。
- 退款文案逐语复用现有积分页政策；支持使用既有邮箱，不索取密码、验证码、Cookie 或完整卡号。

会员中心和积分页继续保留尚未开放/规划中的音乐描述。本说明采用正式开放后的条件语气，不能据此提前宣布上线，也不改变软件、小说等原有权益。

## 可达性与隐私

音乐页静态渲染两块可展开说明，不依赖目录成功或登录，也不请求媒体。完整隐私说明复用 `MusicPrivacyNotice`；统计仍为可选、缺省关闭，撤回与本机清除不删除既有账号、会员和财务记录。托管访问日志与统计事件分开说明，不能声称没有任何服务器记录。

统计控件的隐私链接在新标签页打开同语种音乐页的隐私区，避免手机筛选面板遮挡说明；新页仍按现有合同无源暂停。音乐页页脚的隐私/条款链接定位本页说明，支持直达既有邮箱；其他页面的页脚保持原样。通用条款索引复用同一收听组件，隐私索引继续复用既有隐私组件。

浏览历史规范化仅保留 `#music-privacy` 与 `#music-listening` 两个固定锚点，避免首屏整理 URL 时丢失说明落点；会员回跳片段仍按原流程消费，未知片段不保留。锚点不写入 musicPanel，不携带身份或资格。

不新增页面、预发白名单或服务端逻辑，不打开统计，也不把文案审校当成运营地区的法律合规结论。统计适用依据、清理与备份保留策略仍按 M4_ANALYTICS_PRIVACY 单独验收。

## 验证与后续

全仓测试和主站构建继续运行；构建检查覆盖四语说明、同页隐私入口、音乐页脚正确目标、非音乐页脚不变和单一 audio。既有会员本地化测试锁住退款文案与原积分页一致；隔离预发打包器验证八页依赖闭包。浏览器检查说明展开、手机筛选里的隐私入口和无源暂停。

无 Worker、数据库迁移、配额、支付、会员读写或业务开关改动。部署须在实现独立审查后按预发维护 runbook 另行执行；回退仅撤销新增告知和页脚目标，不回退数据。下一项是 M6-04 运维就绪与关闭方案；未验收的真机/性能/生产准备不能被本切片替代。
