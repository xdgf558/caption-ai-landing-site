# M1-01 / M1-02 数据与策略基础

基线：已合并 PR #119 的 main@dee3cdf。只交付隔离数据模型与纯策略模块；没有音乐路由、页面、播放器、生产绑定或上传/发布接口。

## 迁移边界

`migrations-music/0001_music_foundation.sql` 只用于未来独立 MUSIC_DB。它不在现有 `migrations/` 下，不能应用到 WAITLIST_DB；仓库生产 wrangler 配置不变。M2/预发资源获准后再设置独立 binding 与 migrations_dir。迁移没有真实曲目、虚构统计或会员数据种子。

这是全新音乐库，不存在已识别的 v1.0 音乐表结构。遇到已有同名表时迁移报错，不用 IF NOT EXISTS 掩盖旧结构，也不猜测旧内容付费策略。若以后发现旧音乐数据库，应先单独核对并追加明确的迁移；不可拿本初始化文件覆盖或重跑。已有显式 free 发布版在新草稿编辑时仍保持 free，已有公开承诺不得自动加付费墙。

14 张 STRICT 表覆盖歌曲、修订、资源、权利审核、证据关联、歌单及排序、上传会话、审计、幂等结果、设置、原始事件、日聚合和最小归因引用。时间统一存 UTC epoch milliseconds，JS 边界转成严格规范的 UTC ISO 字符串。ID 由后续服务端写入口生成 UUID；公开投影拒绝无效 ID，不能把文件名或对象 key 当路由。

- 复合外键约束发布指针及素材属于同一歌曲；资源用途和试听来源额外由触发器检查。
- sealed 修订不可修改/删除；validated 资源不可原地更新。发布过的 slug 和首次发布时间保持稳定。下架保留旧版，归档前必须先下架。
- 歌曲修改创建新 draft；公开投影只用 published_revision_id。发布操作应先清理草稿指针，再封存修订并切换发布指针，全部留给 M1-04 同一条件事务实现，不能分成线上无保护写入。
- 私有证据必须属于同一歌曲且为已验证 evidence，封存后审核及证据关系也不可变；需要纠正时下架并创建新修订，不篡改原审核。
- 审计只追加；完成/拒绝/过期上传会话不可重新打开；幂等键由 actor/route/key 联合唯一。INSERT OR REPLACE 也不能绕过封存和审计保护。
- 统计用固定列、枚举及去重键，不接收任意 attributes_json；日聚合以 UTC 零点毫秒表示日期，未生成行不等于 0。归因没有账户、VIP 状态或会员到期字段，不能用于鉴权。

以上是结构约束，不是完整发布服务。M1-04 仍需权利资料商业资格、审核适用性、资源存活、CAS、catalogVersion/审计/幂等同事务与零命中回滚；M1-05 仍需真正解析 MP3。不能仅凭手工写入 sealed/validated 就声称生产内容已安全发布。

## 策略与公共投影

`src/music/policy.js`：新草稿默认 vip；只有创建新草稿函数能补默认值，持久化策略缺失或未知必须拒绝。抢先期默认 7×24 小时且明确指定结束后 free/vip；在 `now === earlyAccessUntil` 时立即切换。UTC 不接受本地时区、非法日历日期、自动滚动日期或隐式时间。文案修改保留已结束窗口，实际策略更改递增 policyVersion。`variantRequirement` 强制 full/preview，仅返回所需资格，不授予 VIP；实际会话适配属 M1-03。

`src/music/catalog.js`：显式组装允许字段，使用真实原文作为四语回退；目录不含账户、会员期限、canPlayFull、对象 key、hash、私有证据、管理员、上传信息或故事全文。封面只构造本站受控接口路径，不输出外部资源 URL。音频 URL 留给未来客户端按 ID/版本/variant 构造。

坏的修订、策略或资源记录被排除；合法条目仍可返回。目录最多 500 首，歌单只保留该目录中的公开曲目，不能改变其 VIP 策略。排序稳定，ETag 对实际公共投影做 SHA-256，包含语言与自然到期后的 effectiveAccess；不把当前时间直接写入投影，避免无变化时每毫秒换 ETag。`nextPolicyChangeAt` 是最早的待发生切换，客户端以后用它安排重拉；M2 的 HTTP 缓存仍必须覆盖自然过期，不得只凭缓存版本允许访问。

当前 preview 检查仅针对已有的验证结果做防御：独立 ID/key、同一完整音频、有效原曲区间、默认 45 秒/半长及 250ms 容差。它不读取 MP3、不验证语义同源，不是 M1-05 测时完成的证据；配置化发布上限及绑定测量证据后续接入。元数据中正好有这些数值不代表真实音频合格。
