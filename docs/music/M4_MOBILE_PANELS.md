# M4-02 详情、移动交互与大字

基线：M4-01/#142，main@86d06a9。用户选定第一套手机设计：纸色曲库、小封面列表、底部详情入口与独立播放底栏。沿用现有 Astro 页面与播放器，非新建原生应用；设计图和执行材料仅本地保留。

## 页面与操作

- 48rem 及以下使用单列曲库，收听方式/歌单/标签进入筛选面板；原站导航与语言选择移入手机菜单。没有新增首页音乐入口或导航目标。
- 点击歌曲文字打开详情，点击独立播放按钮才请求播放。手机详情使用原生 dialog；同一个详情节点在桌面回到右侧侧栏。
- 详情中保留当前音频的同一组底栏控件：查看 B 时底栏仍显示真正播放的 A。队列面板替换详情面板，不叠加两个播放器。手机上一首/下一首放在队列面板，随机和循环也在队列内；桌面底栏保留上一首/下一首。
- 筛选即时生效；“查看歌曲”、关闭或 Escape 保留已经选择的条件。列表播放仍按当前结果重建队列，底栏恢复仍保留原队列；说明可从筛选或队列查看。
- 新增手机顶部封面只复用已校验的同源公开封面地址。不会从目录接受任意媒体 URL。无音源时仍不设置 audio.src，也不自动播放。

## 历史、焦点与生命周期

面板仅持有 DOM 和浏览历史接口，不接收 audio、queue 或资格 API。history.state 的 musicPanel 只包含当前挂载的随机标识与面板类别；不会成为播放令牌，也不进入 URL、localStorage 或 BroadcastChannel。

打开面板新增一条同 URL 的历史状态；面板间切换替换该条状态。未改浏览条件时关闭返回打开前的状态；已改筛选时清除面板标记并保留新条件。浏览器后退/前进恢复同一页面的浏览和面板状态，不重建音频。关闭后立刻请求另一个面板，会等正在进行的 Back 完成后打开，避免迟到 popstate 关掉新面板；重复关闭不会后退两次。

原生 dialog 提供背景不可操作语义；Tab/Shift+Tab 在可见可用控件之间循环，Escape 和关闭按钮共用关闭路径。关闭后优先回到触发按钮；该行已不存在时回到仍可见的底栏入口或搜索。切换到桌面关闭面板、还原原节点；页面真正退出时清理监听、ResizeObserver、样式与历史标记，bfcache 仍沿用原播放器生命周期。

## 小屏与大字

主要按钮、输入框、选择器和摘要触控区域至少 44px。文字使用可随根字号变化的单位；窄内容宽度下顶部装饰封面让位于文字，底栏信息与操作换行。底栏限制在半个视口内，必要时可内部滚动；详情和筛选也有独立可滚动区域。

ResizeObserver 测量实际底栏高度，设置页面尾部留白、根滚动留白和详情底部位置；包含底部安全区。音乐页面使用 viewport-fit=cover，不改变其他页面的 viewport。减少动态效果偏好关闭音乐页动画和过渡。大字下跳过导航链接按自身高度移出屏幕，避免固定负 top 露出残片。

## 队列确认修复

M4-01 文案替换留下了损坏的“移除当前曲目”选择器。本包恢复四语文本插值和显式确认；在选择“移除并停止/播放下一首”前，仅显示确认，不完成移除。文本通过 textContent 写入。

## 验证与复现

`npm test` 包含新的 `test:music:panels`：面板历史、筛选提交、切换/重置、旧挂载标记、异步 Back 竞态、移除确认及双入口焦点恢复。原播放器、队列、资格和系统媒体控制测试继续保留。

本地通用预览：先 `npm run build`，再使用 `MUSIC_LIBRARY_PREVIEW=true MUSIC_PLAYER_PREVIEW_SCENARIO=mobile-design MUSIC_PLAYER_PREVIEW_PORT=4211 node scripts/serve-music-player-preview.mjs`；路径沿用四语音乐页。`mobile-large-text` 场景仅在本机返回的 HTML 注入 200% 根字号，不能作为系统字号或真机验证结论。两个场景使用四首合成 WAV 与隔离封面，不读生产身份、不代理远程服务。

本地构建、浏览器 320/390/768/桌面与横屏、200% 根字号、菜单四语、详情/队列/筛选/返回/焦点和“看 B 不换 A”已检查。执行截图、日志和设计对照不随 PR 发布。
