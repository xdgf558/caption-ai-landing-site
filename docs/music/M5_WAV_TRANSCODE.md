# M5-01A 后台 WAV 转 MP3

2026-09-12。用户授权进入 M5；本包基于待审 #147，先交付已确认的浏览器转码。专辑模型/管理、整张批量上传和四角色预览后续分别评审，不把本包当作 M5 全部完成。无 Worker 服务端、迁移、配额、业务旗、支付/VIP 或部署改动。本地执行记录、截图和 session 材料不进入 PR。

## 管理员流程

在既有 `/admin/music/` 素材页选择 WAV 后，按钮变为“转换并上传”。选择文件本身不转换、不创建上传会话。点击后在独立 Web Worker 内转换，显示进度和“取消转换”；主界面保持响应，同一工作区只允许一个转换/写操作。转换完成才计算 MP3 哈希、保留原幂等会话、上传并由服务端验证；仍需显式保存素材到草稿，以及后续试听、技术核对和显式发布；来源材料按 [OPTIONAL_SOURCE_MATERIALS](OPTIONAL_SOURCE_MATERIALS.md) 改为可选。

原 WAV 与解析出的 PCM 只在管理员浏览器里使用，不发送到服务端，不写入 sessionStorage / localStorage / IndexedDB，不调用外部转码服务。读取按固定块进行，最多每次 9,216 个采样帧（双声道 32 位时 72 KiB），不会一次解码整首 WAV；输出 MP3 缓冲有 32 MiB / 4 MiB 上限。浏览器内部的 Blob、编码器和结构化复制仍有额外内存成本，不能将此上限称为进程峰值内存保证。

## 输入与编码边界

| 项目 | 本包合同 |
| --- | --- |
| WAV 容器 | 小端 RIFF/WAVE，单个 fmt 和非空 data；严格文件/分块长度，最多 256 块；忽略其他元数据，不复制标签 |
| 采样 | 单/双声道；32、44.1、48 kHz；PCM 16/24/32 位或 IEEE Float 32 位；支持对应 WAVE_FORMAT_EXTENSIBLE 标准 GUID 和单/双声道布局 |
| 不支持 | RF64、大端、压缩 WAV、多声道、其他采样率；明确报错，不猜测、不隐式重采样 |
| 原 WAV 上限 | 完整音频 256 MiB / 20 分钟；独立试听 32 MiB / 45 秒；至少 0.1 秒 |
| 输出 | MP3 CBR 192 kbps，保留采样率与声道；高位深截取到有符号 16 位，float 四舍五入到 16 位、超满幅裁限；NaN/Infinity 拒绝。无响度归一化、抖动或元数据复制 |
| 试听 | 管理员先裁好独立试听 WAV，填写原曲起止区间；不自动截取完整曲。WAV 时长与填写区间差异超过 250 ms 在预留前拒绝；服务端仍独立核对 MP3 测得时长、原曲关联、45 秒/原曲一半限制 |
| 资源失败 | 取消、损坏/不支持文件、组件失败或 10 分钟超时会终止 Worker；不创建上传会话。可重新选择文件或再次点击重试，不自动降级上传 WAV |

转换包含 MP3 编码延迟与帧填充；界面和审核采用服务端测得的 MP3 时长，不以 WAV 声明替代。生成音频仍需人工试听，结构测量不证明音乐质量、授权或试听语义同源。真实 Safari/iPhone、较慢设备、大文件体验和生产 Access 静态资源链路留 M6/隔离预发验收。

## 上传与恢复不变量

- 首次转换失败/取消时不会创建预留；恢复期间的原预留继续保留。取消入口只存在于转换期间；上传已经发出后不显示“取消”并虚假释放额度。
- 成功后复用原 `/admin/api/music/uploads`、SHA-256、32 MiB/4 MiB、Origin/CSRF、If-Match、幂等与服务端媒体核验。WAV 不会扩大后端格式白名单；服务端不接收转换参数或信任前端测时。
- 上传 journal 只额外记录固定配置标识 `lamejs-1.2.7-cbr192-pcm16-v1`。不存 WAV、PCM 或 MP3 字节。原有账号隔离、会话 ID、输出大小/哈希与幂等键保持。
- 预留回执不明：先以原幂等键核对；确认 reserved 后可重选原 WAV，按同一固定配置重新转换，只有 MP3 大小与哈希均等于原记录才允许 PUT。不同输出拒绝，不能创建替代预留。旧编码配置不能由新配置自动替换；不匹配时需要原 MP3 或保留对应编码器。
- 已写入/上传中或 PUT 回执丢失：先 GET，会话已进入 writing/uploading 时只走 complete，不加载编码器、不要求原文件、不重复 PUT；completed 只恢复关联。过期/拒绝的预留继续计费，由既定维护流程处理。
- 转换可能耗时较长，预留仍由原 mutate 再查管理员；reserved 恢复转换后、PUT 之前再次查询 `/status` 核对账号。账号变化拒绝写入。离页终止转换，刷新不自动恢复转换或 POST。

## 编码器与可复现检查

固定 `@breezystack/lamejs@1.2.7`，无新增传递依赖。浏览器按需加载同源独立 ES module `/vendor/music-mp3/lamejs-1.2.7.js`，是 npm 包内 dist 文件的未修改副本；不混进应用 bundle、不使用 CDN、SharedArrayBuffer 或跨源隔离头。独立文件允许替换兼容编码器。

LGPL-3.0 编码器署名、完整 GPL/LGPL 文本、上游说明和对应源代码归档随静态资源提供，素材页有链接。源码锁定 npm `gitHead` 的 `1fb0ef5fa177413107e2e107d054a9b994e3f79c`；哈希与重建说明见 `public/vendor/music-mp3/NOTICE.txt`。测试核对安装包、部署副本及源归档哈希。隔离预发需要沿用 Access 检查这些新静态文件的可达性；本包不扩大白名单。

`npm run test:music:wav` 已纳入 `npm test`，覆盖真实编码/服务端解析、哈希可复现、输入预算、异常采样、分块与取消/迟到消息/超时/重试。`scripts/music-admin-browser-tests/workspace.spec.mjs` 在既有 CI 的临时 D1/R2 后台中覆盖 WAV 完整与试听上传、实际 MP3 播放、取消/组件失败零预留、丢预留原键恢复/不同输出拒绝、丢 PUT 只核对不重传。另运行既有 admin-client、uploads 与构建检查。
