## 产品范围

音乐小站是现有个人网站的一部分，以站长实际提供且经人工核对适用于本站运营的作品为内容。普通访客可免登录完整收听免费精选；VIP 曲和抢先作品提供独立短试听；现有有效全站 VIP 自动获得受保护曲目的完整收听权，不额外收费。

音乐不新建会员、到期账本或结账接口，不调整 VIP 价格、周期或原商品权益，不将积分余额、小说单项权限、管理员身份或页面 VIP 图标作为全站 VIP。现有游戏商品、独立软件及单章购买仍遵循原规则。

首发包括曲库、搜索筛选、推荐歌单、播放器与队列、详情故事、TXT/LRC 歌词、本机收藏与记录、四语移动体验、后台管理、安全媒体交付和可关闭的最小第一方统计。后台沿用现有登录与工作区，日常发布流程保持简洁，必要的权利和发布核对不能省略。

P1 才考虑单曲 SEO/专属分享图、深入留存、歌词时间点编辑、批量导入、睡眠定时、夜间主题及缓存优化。全站跨页不断播、账号收藏同步、PWA、多码率等留待 P2；下载、离线和商用授权需另行评估。独立音乐套餐、按次扣点、自动续费改造、访客上传和在线 AI 生成不属首发。

## 技术和安全约束

- 沿用 Astro 和现有 Worker，音乐代码按独立模块接入；一个 HTMLAudioElement，禁止为了音乐重构全站导航或引入全站 ClientRouter。
- 拟新增独立 MUSIC_DB 和私有 R2 Standard MUSIC_BUCKET；不改既有桶权限，不把正式音频放进 Git/public/dist。数据库与桶尚未创建。
- 页面内浏览、搜索、歌单和详情切换不断播；整页刷新、语言切换或去其他栏目保存进度，回来保持暂停，用户手动继续。
- full 与 preview 分别存储，试听绑定当前完整资源。上限为 min(配置上限, 完整时长的一半)，默认配置 45 秒；编码容差最多 250ms。必须服务端测量，不能发完整版再用 JS 限时。
- free/vip/early_access 由服务端判断。抢先默认 7 天且必须预设结束后 free/vip；到点自然生效，不依赖 cron。未知策略不得变成免费。
- GET、HEAD、Range、条件请求都先过当前发布状态和资格检查。VIP 资格故障返回 503，不能放开完整版；免费曲与试听不依赖 VIP 查询成功。
- 媒体、资格、草稿和后台按规格使用私有/no-store 策略；公开 catalog 不夹带用户身份、到期时间、R2 key 或权利证据。
- 发布版本不可变，新草稿不影响旧公开版；If-Match、幂等与事务内条件守卫防并发副作用。修改音频或权利相关内容须重新审批。
- 音乐资格适配只读；退款关联若未明确是上线依赖，不能用负积分自行封禁，也不能把音乐统计变成权益来源。
- 统计属首发实现范围，但默认关闭；隐私条件满足后另行启用。无可靠指标显示 unavailable，不伪造播放、转化或音乐收入。
- 不承诺 DRM、到期瞬间追回已传字节、任意锁屏保活、跨页播放或第三方商用权。
