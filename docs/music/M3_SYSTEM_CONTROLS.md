# M3-04 系统媒体控制与标签页协调

`musicSystemControls.js` 是现有单音频内核、队列和资格生命周期的渐进增强，不创建第二个 audio、不增加媒体请求代理或授权渠道。正式页面与独立收听链接留 M4 接入路由；本包仍只提供隔离本机预览。

## 系统动作与媒体信息

首次挂载、浏览曲目和资格读取不注册系统动作，也不设置媒体信息或请求音频。通过 M3-03 同步资格守卫的主动播放，才申请本页的 Media Session 并公告播放优先权；这发生在同一用户动作里，`audio.play()` 前没有 await。

逐项尝试注册 play、pause、stop、nexttrack、previoustrack、seekbackward、seekforward、seekto。不支持某个动作不影响其他动作，缺少 API 时保留网页播放器。系统 play 复用 `queue.playCurrent()`，正在播放时不重复调用；前后曲复用队列的完整曲过滤、三秒回头及有界故障规则。seek 默认前后 10 秒，只落在当前资源的合法 seekable 范围，暂停时拖动仍保持暂停。stop 卸源、保留选择并将位置归零，后续需主动播放。

曲名、创作者来自已校验目录；封面只重建同源 `/cover?v=...`，不接受目录传入的外部 URL。试听标题带“试听”，系统进度使用短文件自身的时长与位置，不加试听源起点。载入/播放/缓冲对应系统 playing，暂停/结束/普通错误对应 paused；卸源或清空选择清除媒体信息、位置并设为 none。保留的 play 回调仍必须经过现有队列和资格守卫，不能用系统操作绕过到期或登出限制。

位置仅在当前资源 metadata 就绪、时长/位置/速率有效时发布，速率来自原生 audio。按整秒与状态/资源变化去重，不增加轮询定时器；非法或未知时长清位置，位置 API 抛错后停止重复尝试。每次注册有代次保护，旧回调在失权、重新注册或销毁后失效。

## 标签页播放优先权

仅本站音乐播放器监听 `station-cat:music-playback:v1` BroadcastChannel。消息字段严格限于 version、type=claim、随机 instanceId、stamp；不含账号、Cookie、资格、曲目或媒体地址，不写 localStorage。消息只能让其他音乐实例暂停，不能授予资格或启动播放。

内核在主动播放通过守卫后通知协调层。列表播放、播放全部、底栏恢复、手动切曲及系统播放/切曲属于主动动作；自动续播、故障跳过、被拒绝的播放、被动选曲、仅暂停或 seek 不公告新优先权。另一实例的新 claim 会使当前运行或等待错误分类的实例暂停，并清除本实例拥有的系统动作；迟到 play Promise、ended/error 和 access 响应仍受既有守卫约束。收到 claim 不回发暂停消息，避免回声。

stamp 使用本地毫秒时钟并至少大于已见的值；同一毫秒并发用随机实例 ID 确定唯一顺序，较旧消息和自身回声忽略。只保留一个最新 claim，空间不随标签页或播放次数增长。异步广播到达前可能短暂重叠；此机制是同源浏览器内的尽力协调，不是跨设备锁或严格分布式互斥。缺少/阻止 BroadcastChannel 时保留基本播放并显示标签页独立播放提示。暂停的一页不会因别页关闭而自行恢复。

## 音量、隐藏页面与清理

只在内核初始化且无 source 时试写并恢复音量；写入抛错或读回不一致时，禁用软件滑条并提示使用设备音量。后续写入同样核对，静音写入失败也降级。移动布局继续提示使用设备音量。读回成功不等于所有设备的实际输出音量已验收，真机仍由 M6 覆盖。

隐藏页面停止播放器的 DOM 进度渲染和加载动画，保留原生音频、资格到期处理及低频系统进度更新；回到前台由 M3-03 重查资格并渲染当前状态。没有 Wake Lock、高频后台循环、全局按键拦截或对其他 audio 的遍历/暂停，不改游戏音频。

挂载由 WeakMap 保证幂等。销毁卸除播放意图订阅、状态订阅、已注册的系统动作并关闭频道；如果系统元数据已被其他组件接管，不清其状态。目录重建先中止旧封面监听，避免多次重查留下已移除的行。pagehide 非 bfcache 时走完整销毁；bfcache 保留实例，恢复仍服从 M3-03。

## 验证合同

`npm run test:music:system-controls` 已纳入 `npm test`，覆盖权限守卫、系统动作/位置、并发与迟到 claim、错误中接管、降级、外部组件接管和重复挂载清理。虚拟 30 分钟事件压力检查监听/广播规模有界，不能替代实际浏览器时长测试。

本机预览构建后运行原 `serve-music-player-preview.mjs`，默认免费合成 WAV 场景可做 30 分钟列表循环及切换标签页观察。`?system-test=1` 仅在独立预览启用测试面板：展示原生媒体信息和有界事件计数，按钮调用已经注册的动作回调，可模拟音量写入限制及销毁。它不是实际蓝牙/锁屏按键，也不进入主站构建；没有新增账号、Cookie 或远端接口。

实际观察需记录：初始无音频请求；一个 audio；前后曲/暂停/seek/stop；另一页接管与手动切回；30 分钟内的自然结束/续播、错误、控制台及结束状态。执行记录、截图、状态文件和 session 材料仅存本地忽略目录，不进入 PR。iPhone/Safari、蓝牙、来电中断、锁屏、网络变化及真实 MP3/Range 仍按 M6 验收，不承诺锁屏保活、关页播放或全站导航不断播。

参考：[Media Session 动作](https://developer.mozilla.org/en-US/docs/Web/API/MediaSession/setActionHandler)、[位置状态](https://developer.mozilla.org/en-US/docs/Web/API/MediaSession/setPositionState)、[媒体音量](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/volume)。
