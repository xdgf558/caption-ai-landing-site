## 范围

新增 /admin/music/，仅在 Admin V2 增加入口。沿用文章编辑器的左右工作区、字体、绿色主按钮和中性底色，使用 Product Design 的上下文/参照检查和视觉 QA；复用现有 Lucide 和品牌图，不重新做全站设计。

左侧搜索/状态筛选/游标翻页，右侧基本资料、素材、审核发布三个键盘可切换 tab。四语曲名和简介可展开编辑；故事、署名、分类和 free/vip/early_access 策略走原接口。日期以浏览器本地时区输入，发送严格 UTC。policyVersion 从已发布策略推导，不从编辑计数生成。回车只保存草稿，发布/下架/归档另行确认并填写理由。

完整音频、独立试听、封面、歌词和凭证按现有大小/格式限制上传。浏览器逐 64 KiB 计算 SHA-256，不整曲读进内存；服务端仍独立校验。试听必须指定原曲和起止秒数；替换原曲会清掉旧试听引用。完整/试听使用受保护素材端点和原生 audio 控件，互斥播放，不自动勾选试听确认；不是公开播放器或资格模拟器。

权利表单包含来源、套餐、严格时间、商业授权、输入/封面/歌词说明、凭证与例外授权；默认待审核。技术审核复用四个显式布尔与服务端重验。有未保存资料/素材时不能审核；未提交权利更改时不能技术审核/发布。审核完成后折叠详细表单。新草稿使旧核对失效，已发布版本不被修改覆盖。

显示真实配额与公开入口开关、只读审计分页。未实现的歌单、统计、四角色公开预览不显示可用入口；M5-01/02 保持部分完成，不把本轮基础 UI 当作整个 M5 DONE。

## 恢复与安全

- 所有数据走现有 /admin/api/music。唯一 API 变化是已鉴权 /status 返回 actorId，用于客户端隔离恢复记录；不改变 JWT/allowlist/Origin/CSRF。
- JSON 写入先把路径、正文、If-Match 与幂等键记入账号隔离的 sessionStorage，再发请求；未知响应锁定后续写入，只有显式原键重试。重载不自动 POST。每次写前重新查询 /status 核对账号，账号变化拒绝重放。存储不可用则失败关闭。
- 恢复记录仅此标签页，关闭标签页后不保证保留。不保存音频、Cookie 或 Access token；编辑文字/权利说明及上传会话引用可能保留在该标签页的 sessionStorage。跨标签页编辑仍由服务端 CAS 防护，不引入新账本。
- 文件 PUT 不盲目重传。会话保留后，GET 确认；uploading 只 complete；reserved 需重选 hash 相同的原文件。结果不明的同类上传禁止另开会话，先核对。拒绝/过期不会删对象、清审计或释放配额。
- 草稿切换、筛选、翻页、刷新有未保存提示；异常保留编辑内容。媒体使用受保护 UUID 路径，无外站 URL 或裸桶 key。
- /admin/ 的现有入口鉴权仍在，页面 noindex，不进入 sitemap。前端状态不是授权边界；原支付、VIP/积分写入、公开媒体和生产配置均未修改。

**该预览器和 scripts/helpers 测试 Worker 使用假管理员、256 MiB 测试配额和上传开关，禁止部署。** 应用代码不导入它们。没有执行音乐生产迁移，也不将音乐 migration 应用到 WAITLIST_DB。

评审剩余边界：浏览器刷新仍恢复标签页 journal，不先 GET 曲目；主动重新载入会 GET，旧编辑写入由服务端 CAS 拒绝。此轮不改变未确认操作或未保存编辑的恢复策略。测试预览器仍禁止部署。
