# M4-04 分享与会员回跳

## 范围与权限

分享公开歌曲或歌单，保留四语入口；会员中心提供显式返回音乐的链接。URL、浏览位置与本机偏好都不提供播放权，`/audio` 仍逐次执行原有发布、版本和 VIP 核验。本包不修改 Worker、迁移、支付/积分/VIP 账本、业务开关或首页导航，不部署。

## 分享链接

- 当前歌曲和所选歌单各有分享、复制按钮。链接由 `location.origin`、规范音乐路径及公开 `track` UUID 或 `collection` slug 构造；每条分享链接只包含一个目标。
- 繁体规范路径为 `/music/`；简体、英文、日文分别为 `/zh-hans/music/`、`/en/music/`、`/ja/music/`。不接受目录提供的任意媒体 URL。
- 用户点击时同步调用 Web Share；取消不报错也不复制。不可用或失败时尝试剪贴板，剪贴板失败则显示可选中的只读文本。迟到结果不能更新已切换目标的提示。
- 打开链接不拉音频、不自动播放、不替换正在播放的队列。封面和歌词沿用公开展示合同，分享链接不是下载地址。
- 社交预览沿用音乐页通用元数据；查询参数没有独立静态 HTML，本包不承诺逐曲 OG 卡或搜索收录。

## 目录之外的落点

首页目录和每个公开响应仍至多 500 曲。`track` 不在当次目录时读取既有单曲公开接口；所选歌单读取既有完整歌单接口，按其 `trackIds` 顺序展示，不只取首页目录的交集。返回身份、schema、成员集合不符视为不可用。404/410 明确提示已不可用，其他失败提示重载；不静默选择第一首替代错误目标。

内存查找表至多 1502 曲：当前队列元数据 500、当次目录 500、所选歌单 500，加当前音频与目标单曲各一项。展示、队列仍各限 500；每次重读重建查找表，不无限累积。保留的队列元数据只是显示和客户端选择提示，非发布或授权证明。当前音频和请求目标必须来自当次公开读取；其余旧队列成员可能到播放请求才发现下架，仍由 `/audio` 拒绝并走原有一次 `/access` 分类。

浏览读取不重查/清空资格，不停止当前音频。读取期间用户另起队列，旧读取不能替换新音频的查找表；资格刷新仍按原生命周期卸载受保护 full。媒体已判定失效的版本不会因浏览而恢复，显式重新核验/前台刷新才可重试。歌单落点不被无关的本机“上次曲目”覆盖，保存的音量等偏好仍可恢复；所有恢复保持无源暂停。

## 会员往返

1. 音乐入口构造对应语言的会员中心路径，参数仅为 `source=music` 与规范相对 `returnTo`。`returnTo` 经过共用 `safeReturnPath` 和精确音乐路由白名单，再只保留有效公开 ID。外站、编码绕过、非音乐路径及重复导航参数不能建立返回入口。
2. 音乐来源的登录留在会员中心，让用户处理现有会员业务；页面显示“返回音乐”，不自动兑换或跳回。其他来源保持原登录回跳规则。
3. 现有积分购买仅把安全导航上下文放入原 checkout `returnPath`，支付后仍回会员中心。积分包、价格、兑换锁、账号绑定幂等键、回执及权限逻辑不变。
4. 用户主动返回音乐，链接附带 `#membership-return`。片段只请求一次新的只读同步，随后由音乐历史状态去掉；不保存身份，也不作为支付成功或会员有效的证据。
5. 新页面首次保持暂停，调用原资格生命周期读 capabilities 和公开目录。有效会员即停止等待；交付未开启时单独提示。已知匿名提示登录；其他未确认状态采用 2/4/8/10 秒退避，之后每 10 秒一次，间隔从上次读取完成算起，单次访问最多 60 秒。隐藏页面不开始新的轮询。截止取消本轮未完成的读取，迟到响应无效，且不能取消更新一轮的手动/账号刷新。
6. 到期仍未确认则保留会员中心入口与手动核验，不重复促购，不因 URL 成功字样放行。M3 的前台/到期/账号变化复核仍独立有效；后续核验成功或失效会更新返回提示，不重启自动轮询。

回跳模块不写 localStorage、Cookie、BroadcastChannel 或任何账户数据。`stationcat.music.v2` 的既有偏好白名单不变。不新增登录或 Cookie 通道。

## 可复现检查

```sh
npm run test:music:sharing-return
npm run test:music:lyrics-local
npm test
npm run build
npm run build:music:player-preview
```

`scripts/payment-browser-tests/membership-safety.spec.mjs` 增加登录显式返回、恶意回跳和 checkout 导航合同，复用现有支付浏览器 CI 的全假接口；不得用真实付款执行测试。

本地交互预览（合成音源和只读会员夹具，无代理、无外部绑定）：

```sh
MUSIC_LIBRARY_PREVIEW=true MUSIC_PLAYER_PREVIEW_SCENARIO=sharing-return MUSIC_PLAYER_PREVIEW_PORT=4216 node scripts/serve-music-player-preview.mjs
```

访问 `/zh-hans/music/?collection=quiet-days`，或目录之外的 `/zh-hans/music/?track=22222222-2222-4222-8222-222222222222`。场景首页仅一曲，歌单含三曲；会员无有效 VIP，便于观察 60 秒截止。`sharing-large-text` 场景使用 200% 根字号。服务仍只允许 `127.0.0.1` 的 GET/HEAD，所有 POST 拒绝；会员表单不能登录、兑换或支付。此预览不能部署。

本机截图、执行记录、请求计数和 session 材料不随 PR 发布。真实 iPhone、Web Share 系统面板、云端身份/支付同步、真实媒体与跨实例验收仍归 M6。下一开发项为 M4-05 最小统计与隐私合同，生产开闸另行决策。
