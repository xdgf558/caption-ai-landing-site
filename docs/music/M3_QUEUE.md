# M3-02 队列与播放控制

队列层位于 `musicPlayerQueue.js`，复用 M3-01 的单一音频内核。`musicQueueControls.js` 负责队列面板和按钮；生产页面仍未引用音乐组件。队列状态只在内存中存在，不写入会员状态、播放快照或持久存储。

## 快照和可听范围

从列表开始播放时，复制当时结果的顺序及公开曲目信息，包括访问类型、版本和试听元数据。从列表换到另一首，或暂停后再点击列表的播放按钮，同样使用此刻列表重建队列。之后仅浏览列表或目录排序变化不替换待播顺序。点击当前正在播放的行只暂停；底栏恢复播放保留已有队列。“播放全部”也是显式替换队列动作。列表旁与队列面板均说明此边界。

快照最多 500 首，重复 ID 只保留第一次出现。超限保留前 500 首并提示；明确选择的曲目若在上限之外，不替换正在播放的队列。追加只增加尚未存在的曲目，不会更换当前音频。

播放全部、手动前后曲切换到其他歌曲和自动续播只选择当前已知可完整收听的曲目：free 总是可选，VIP 要求 capabilities 的完整播放许可、交付开关和有效会员状态同时成立。资格未知或读取失败时不自动进入 VIP 试听。所有音频仍由 `/audio` 逐次核验，队列不能授权。

用户可以明确选择 VIP 单曲试听；试听自然结束后停止，repeat=one/all 都不会重播或进入下一段试听。手动下一首恢复按可完整收听的队列推进。全 VIP、无可完整曲目或空队列给出说明并停止，不循环扫描或发起试探请求。

更新完整目录会重新计算可用性，但保留快照顺序。以后播放使用最新已知的曲目版本；目录明确移除当前曲目时停止并卸载。`updateCapabilities()` 只更新后续选择依据，资格到期/登出通知、网络复核及当前受保护源处理仍由 M3-03 完成。

## 前后曲、循环和随机

- 上一首：当前进度严格大于 3 秒时回到开头，保留暂停状态；恰好 3 秒或更少时选择上一首可完整曲目。
- 下一首：按队列前进，忽略单曲循环。手动切到另一首会开始播放；顺序末尾停止，列表循环可以回到开头。
- 单曲循环：仅完整音频自然结束时重复当前曲目。内核的 ended 状态是队列入口，内核自身不拥有队列。
- 随机：使用已洗牌的待播集合，每轮各曲目至多一次。新一轮包含全部可听曲目；有多首可听曲目时，新一轮第一首不能等于上轮最后一首。
- 随机上一首回到实际播放历史，下一首先重走返回路径；手动返回历史不属于新随机抽取。关闭随机后保留当前曲目，并回到原始队列位置。历史和返回路径各自最多保留 500 项。

权限过滤、不可用曲目过滤和随机抽取都只进行有限遍历。仅有一首可完整曲目时，列表循环可以重复该首；这不适用于试听。

## 移除和故障边界

移除待播歌曲不停止当前声音。移除当前歌曲必须明确选择“移除并播放下一首”或“移除并停止”；没有下一首可完整曲目时停止并卸载。取消确认不改变队列或音频。“清空并停止”同样卸载音频。关闭队列面板不会停止播放，Escape 返回打开按钮。

完整音频失败后自动跳过，但最多允许连续三次失败：第三次失败停止，不发起第四首。已失败曲目在本轮故障恢复期间排除，因此少于三首可选时可以更早停止。跳过 VIP 或已下架条目不增加故障数。试听失败、浏览器拒绝自动播放，以及用户暂停后迟到的媒体结束/错误都不会自动启动其他曲目。

只有明确发起新的播放动作，或完整音频实际连续播放满 10 秒，才清空连续故障计数。暂停、清空、移除并停止、随机/循环切换都不会重置。成功时段同时检查单调时间和原生媒体进度；seek、停顿、缓冲或跳跃进度不能冒充成功收听。

源切换仍使用 M3-01 的代数与播放尝试保护。队列监听去重结束/错误状态；销毁先移除队列监听，再由组件销毁原生内核，不留下后台自动续播。

## 预览和验证入口

```sh
npm run test:music:queue
npm run test:music:player
npm test
npm run build:music:player-preview
npm run build
npm run preview:music:player
```

内核与队列测试共用原生媒体测试替身，覆盖顺序快照、资格过滤、历史往返、跨轮不重复、循环、500 上限、显式移除、迟到事件与故障预算。队列专项已纳入 `npm test`，独立预览继续由 CI 构建。

本机连续故障场景可通过 `MUSIC_PLAYER_PREVIEW_SCENARIO=queue-errors npm run preview:music:player` 启动。它只返回合成错误来验证客户端停止边界，不能替代远程媒体、MP3、Range、VIP 或权利验收。结束后使用默认命令重启正常预览。

本包不修改 Worker、数据库迁移、业务开关、支付/VIP 账本或正式音乐导航。浏览器截图、执行记录、请求计数和 session 材料仅保留在本地忽略目录，不进入 PR。真实设备、媒体交付与资格变化仍按 M3-03/M3-04/M6 分别验收。
