## 执行与交付约定

每个任务开始时更新状态；交付写任务编号、文件、真实测试命令与结果、未验证项、迁移影响、原站回归、回滚边界、VIP/退款证据与下一步输入。不要承诺一阶段必须挤进一个大 PR；优先沿上述职责拆可审查的小 PR。

M0 历史与 M1 实测见 TEST_MATRIX / M1_FOUNDATION / M1_VIP_ADAPTER / M1_PUBLICATION / M1_MP3_VALIDATION；M2-RUNTIME 与 M2-ADMIN 首批实测见 M2_RUNTIME_STORAGE / M2_ADMIN_API，其余 API 仍待实施，不能把原站浏览器测试当成音乐系统测试。PR #120 的幂等回执保护、发布统一校验已处理，空歌单留公共目录接线；#121 重复 Cookie/异常 clock 和 #122 畸形 metadata 的 422 回归已完成，真实预发完整 D1/资格查询仍待授权。未创建的 music 测试命令不得宣称存在或通过。

安全链路优先顺序：真实资格映射与退款结论 -> 策略/发布/试听校验 -> 媒体鉴权与字节协议 -> 播放器和界面 -> 内容及真机/上线。页面设计可在授权后用隔离数据探索，但不能替代这条上线依赖链。
