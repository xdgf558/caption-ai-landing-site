# 手机银色唱机播放器

用户在 M6 期间选定第一套银色唱机方案。本切片沿用四语音乐页面，在 48rem 及以下增加“正在播放”全屏面板；曲库和浏览歌曲详情继续沿用现有结构。

## 展示与操作

- 底栏“正在播放”展开银色唱机；收起、Escape 或浏览器返回只关闭面板，不暂停或换歌。
- 全屏与底栏移动同一个 dock、播放按钮、进度条和上一首/下一首节点。页面仍只有一个 audio，首次打开或恢复本机记录保持无源暂停；显式点击播放仍同步交给现有内核。
- 唱机标题、封面、资格文案与收藏指向 activeTrackId。浏览 B 时，唱机仍显示正在播放的 A。全屏分享也使用 A；分享期间普通渲染不能改用 B，当前曲目或版本变化则关闭旧卡片。
- 歌词入口显式浏览当前播放曲目，并打开已有歌词区域。它不新建歌词加载器或播放状态；已有公开歌词合同不变。
- 循环按钮转交已有队列控件，队列数量订阅现有队列。随机仍在队列面板；完整曲续播、试听结束即停、三次失败停止等规则保持。
- 原生详情、队列、分享面板从唱机进入时保留返回唱机的历史步骤。musicPanel 仍仅含 owner/kind，不增加曲目、资格、媒体地址或 Cookie。

## 视觉和无障碍

银色底座、唱片和唱臂为一张约 99 KiB 的生成 WebP。中心使用已规范化的同源歌曲封面，缺失时显示装饰性猫咪唱片标签；装饰不表示作品已有封面或权利审核通过。

中心标签仅在真实 playing、页面可见且唱机展开时旋转。暂停、缓冲、结束、资格失效或页面隐藏时停止；prefers-reduced-motion 关闭动画。动画不调用音频或资格接口。

面板使用原生 dialog 和既有焦点循环；覆盖背景滚动并在关闭、改为桌面或销毁后还原。小屏使用安全区留白。大字号允许全屏内容纵向滚动，播放按钮宽度受所在列限制，避免覆盖相邻按钮；全屏不沿用底栏半屏高的内部滚动限制。

## 开发检查

先运行 `npm run build`，然后用 `MUSIC_LIBRARY_PREVIEW=true MUSIC_PLAYER_PREVIEW_SCENARIO=mobile-design MUSIC_PLAYER_PREVIEW_PORT=4237 node scripts/serve-music-player-preview.mjs` 打开既有四语音乐路径。`mobile-large-text` 是 200% 根字号夹具；所有音频均为本地合成，不代理预发或生产。

面板历史与分享对象回归随 `test:music:panels`、`test:music:sharing-return` 进入 npm test。复核时应检查：浏览 B / 唱机 A、分享 A、歌词返回、队列返回、暂停拖动不续播、首次无音源、窄屏和大字、桌面还原、减少动态效果。

## 部署边界

隔离预发静态白名单仅增加 `/images/music-turntable-silver.webp`，裁剪包按现有闭包检查包含此依赖。没有新公开页面、API、迁移、业务开关、配额、生产绑定、导航、支付或会员逻辑。

本切片不部署。后续预发仍按维护 runbook 单独进行；本机视觉检查不替代更新后的 iPhone Safari、安全区与后台播放验收。设计对照、截图、运行日志和 session 材料留在本机，不随实现 PR 发布。
