# M5-02 四角色收听界面预演

后台 `/admin/music/` 增加“角色预览”页签，对照访客、普通账号、有效 VIP、过期 VIP。用途是发布前核对已保存的标题、简介、故事、收听按钮及会员提示；不是公开页面的完整渲染器，也不是发布或授权证明。封面/歌词只显示是否关联，声音与图片仍在受保护“素材”页核对。

## 内容与场景

- 每次进入页签或点击“重新读取预览”，先 GET 既有 `/admin/api/music/status` 核对管理员，再 GET 当前曲目；不接受角色、权限、地址或时间请求参数。两个 GET 的开关和曲目是组件快照，不声称跨请求事务或持续实时状态。
- 默认按当前发布状态与实际开关显示。草稿不公开，公开总闸关闭则所有按钮不可用；VIP 交付关闭不降为免费，有独立试听时仍可显示试听，不诱导购买以解决服务关闭。
- 显式选择“假设发布并开放公开及 VIP 播放”才能预演发布后的差异。所有卡片标“模拟”，持续显示实际开关快照与假设说明；不写任何开关或状态。
- 草稿与发布版本独立选择；修改中的表单不会参与预览。新读版本与编辑器版本不一致时提示，保留原表单及 CAS，不替换编辑器、不重放写操作。
- 使用管理曲目响应的 `serverNow` 快照，复用 `effectivePolicy`。抢先场景另可选择恰好到期的时刻；`now === earlyAccessUntil` 按后续 free/vip 处理，无客户端自然推进、cron 或任意时间输入。到期后的真实行为仍由服务器请求决定。
- 作品四语曲名/简介按原文回退；现有播放文案复用 `musicText`。后台角色标签、解释和错误提示保持简体中文。文本使用 `textContent`，不解析作品 HTML。

## 权限与媒体边界

仅内存创建固定角色的显示能力，通过前台已有 `playerVariant` 选出 full/preview/不可用；模拟能力不交给播放器、access、audio 或任何请求。有效 VIP 仍需三个条件全部成立才显示 full。普通账号、过期 VIP 不当作有效会员；无试听时不可回退完整音频。无完整音频时不能演示可播放。

预览自身不创建 audio，不加载封面/歌词/音频，不调用公开目录、capabilities、access、events 或会员服务。点击演示按钮只更新本页说明；会员按钮不导航、不登录、不支付。进入预览卸载素材页声音，返回素材页重建原受保护 audio（preload=none），不自动播放。预览不替代逐请求 `/audio` 鉴权；VIP 封面和已发布歌词匿名可读合同不变。

既有管理曲目 GET 仍经 Access/管理员验证及 `private, no-store`，新增服务器时间与两个版本的有界素材元数据。原草稿/凭证最多 14 个资源，另读发布版缺失引用最多 4 个；不扩大公用 `loadAssets` 写侧上限。响应仍无 object key、hash、凭证正文或播放权限，只增加试听源 ID 与区间用于检查对应关系。这些已验证素材记录不证明桶内此刻仍存在对象；权利、技术与最终发布检查继续走原流程。

每次刷新先清空旧卡片。切曲、切页签、编辑版本变化、写操作阻塞、隐藏页面/离开页面均使迟到响应失效；管理员变化或明确 401/403 清空预览并锁住原编辑器。请求失败无旧结果回退。重新可见时仅当前预览页重读。模拟选项不进入 sessionStorage/localStorage、URL、Cookie、BroadcastChannel、journal 或审计；原工作区仅照旧记录当前页签，不记录“角色检查通过”。

## 验证与运维

`npm run test:music:role-preview` 纳入 `npm test`：角色与缺试听、真实双旗、草稿/发布隔离、early_access 精确边界与后续 VIP、语言回退、字段白名单、缺失/损坏资源、只读请求和迟到/身份失效。管理接口回归确认新时间、发布版资源可读、无 R2/会员库访问或写入、拒绝 role 参数、无身份拒绝读取。

浏览器 CI 在 `scripts/music-admin-browser-tests/role-preview.spec.mjs` 覆盖四视图按钮、无媒体/公开 API/写请求、不保存模拟权限、未保存表单保护、服务端新版本不覆盖编辑器、失败/换身份清空、键盘页签、320px 和纯文本渲染；隔离夹具不进入生产。真实 Access、听众登录/到期、iPhone、音频与跨服务实况在 M6 验收。截图、运行明细、session 材料仅本地保留，不随 PR 发布。

本包无新 API 路径、迁移、支付或资格写入，无远程操作。预发部署仍按 MUSIC_STAGING_HTTP 与既定白名单 runbook 独立执行，需同步发布 Worker 的元数据补充和静态 bundle；旧 Worker 缺少时间/区间时新预览显示不可用，不猜测授权。保持开关关闭，不能把代码合入视为生产开音乐。回退本包无需数据回滚。下一项 M5-03 人工主推与管理收尾。
