## 已实现规则

- 猫的饱腹每 30 分钟减 1；无病时不再自然扣健康。饱腹或疾病耗尽不再设置永久死亡，而是进入免费托管。
- 离线/恢复时负向结算最多 8 小时，饱腹底线 20、健康底线 30；原本低于底线的不凭空回血。超过 8 小时进入托管。隐藏页面的猫咪结算暂停，恢复后走相同结算窗口；超限时间不会留到下一 tick。
- 托管暂停负向状态和常规互动、繁育配对。已发生的妊娠继续观察与生产，不清除怀孕记录。托管猫仍计入图鉴，在房间漫步场景中不出现。
- 接回/基础救助将五项状态至少恢复到 50，清除当前疾病，并提供 24 小时疾病保护。正常医院治疗也提供同样保护期。名字、ID、亲密度、现存疾病历史、领养轮次不重置。
- 严重饱腹/健康不足、缺少必要补给、无力支付治疗时有免费救助。不增发金币、库存、亲密度、经验或任务奖励；已恢复的重复请求不再次生效。
- 玩家饥饿已阻止打工且现金为 0 时，可免费吃应急餐，使饥饿恢复到 40；不增加库存或任务进度。
- 旧版本已经死亡的猫不自动复活。玩家主动接回前保存本机完整备份，失败则不修改猫。首次备份不被后来操作覆盖，按游客/会员存档槽隔离；在存档页可导出。
- 首页、猫咪、医院、图鉴和背包接入一致入口和状态；新增文案覆盖简中、英文、日文。没有添加新图片资源。

## 存档与发布注意

本批发布版本为 `1.23.0`，namespace、内容 manifest、产品页最新版本和三语发布说明保持一致。存档 schema 从 2 升到 3，客户端迁移和云端接收同时升级，使用每只猫的 `careLastSyncAt`，不能依赖云端会剔除的 `meta.lastSyncAt`。归一化保留自定义 ID 的小猫，并修复同胎小猫 ID 碰撞，避免出生小猫刷新后丢失。

云端阻止旧 schema 的页面覆盖已经升级的云存档，即使其 revision 恰好匹配。应提示旧页面刷新，而不是允许降级覆盖。恢复历史云备份仍是显式操作；客户端再迁移后载入。

未来发布必须将前端和 Worker 一起部署到 **Cloudflare 的 caption-ai-landing-site**，生产入口为 `https://wwwstationcat.org/games/cat-life/`。不要部署到独立的 `cat-life-game.vercel.app`。升级后不能只回滚到仅支持 schema 2 的后端；紧急回滚应保留 schema 3 读写与旧客户端保护，或发布前向修复。不需要数据库表迁移。

本机安全备份保留恢复前的完整存档，包括已有本机音乐设置，不上传额外备份文件。云端仍沿用既有的版本备份策略。旧逻辑已清除的数据不能凭空恢复。

## PR #98 复审修复

- 短时恢复不再调用全量 `rebase()`；状态衰减和疾病进度保留未满一个周期的余量，仅跳过已完成的离线感染抽签。托管、接回和时钟回拨仍显式重置。两段 20 分钟以及十段 4 分钟均与连续 40 分钟一致，饱腹从 80 到 79；覆盖 focus、visibility、init、import、cloud 和归一化刷新。
- 生成小猫 ID 时同时检查已有猫和本次生产的兄弟姐妹，并跳过已占用的序号；固定同一毫秒测试双胞胎、多窝同时生产和稀疏旧序号。旧存档若仍包含同 ID 的两条猫记录，归一化为后续记录分配稳定的 `_recovered_N` ID，保留双方字段；原 ID 的既有关系仍指向第一条记录，不猜测歧义关系，也无法恢复已被旧逻辑丢掉的记录。
- v2→v3 优先从五个已知衰减 tracker 与有病时的疾病进度推断最近照护；仅在缺失这类证据时依次回退到猫咪年龄/出生时间、全局 meta。新保存时间和无病时的疾病时间不再遮盖 24 小时前的 tracker。客户端与 Worker 共用五组期望结果测试，不增加数据库迁移。
- 应急餐入口和领取校验使用实时饥饿值，与打工限制一致；补充实际 v3 客户端读取未来 v4、隔离保存/重载及拒绝导入测试，保证不覆盖原始未来存档。
- 版本升级、三语发布说明与 schema 文档已同步；新增 8 组逻辑回归全部通过，其中前三个 P2 与应急餐用例已先在修复前确认失败。

干净 worktree 缺少未跟踪的小说内容空目录，首次全站构建报 ENOENT。创建空的 `src/content/serials`、`src/content/serialChapters` 后构建通过；没有复制私有内容或修改小说构建逻辑。后续部署应沿用正式站点现有内容准备步骤，不能把本次空内容本机构建产物直接上传。

验证边界：浏览器使用 Chromium 桌面和 390px viewport；后台逻辑用受控 `document.hidden` 测试，未做真实 iPhone 锁屏数日的实机等待。截图由 Playwright 输出到忽略的 `test-results/`，不提交大图，也不覆盖此前模块的设计 QA。
