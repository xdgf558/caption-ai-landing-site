# 会员兑换与回跳安全修复

基线：main@19a4436，日期：2026-09-09。属于原会员模块独立修复，不是音乐 M1。用户要求先处理问题再进入下一阶段。

## 已实现

- `POST /api/readers/membership/redeem` 要求同源 Origin、16–128 字符 Idempotency-Key、与可信会话相同的 X-Reader-Account。旧前端缺键返回 400，提示刷新；不生成随机服务器兜底键冒充幂等。
- 新增 0036 迁移：reader_membership_redemptions 仅是账号绑定的操作回执，不是会员资格来源或第二份到期账本。会员唯一来源仍为 reader_memberships。
- 一次 D1 batch 内写回执、扣点、更新会员、写 ledger、存结果。所有后续写由本次唯一 operation_token 控制，冲突重放不能再扣点；最后 NOT NULL guard 将零命中不一致变为 SQL 失败，使整笔事务回滚。
- 同一账号同键永久重放原兑换结果，网络未知结果先查回执；后续有新续期时，redemption 返回原操作结果，membership/balance 展示当前状态。已成功回执不因余额不足或兑换暂时关闭而变成新收费请求。
- 浏览器先保存账号隔离的待确认键再 POST，刷新后可重查；余额为零或兑换已关闭时仍允许核对已有请求。成功并刷新资料后才清除待确认键。Web Locks 防多标签页同时发起，缺少锁或持久存储则在发送前拒绝，不降级成可能重复收费的请求。
- 兑换鉴权使用会话 helper 的只读选项；其他现有调用保留 last_seen 更新行为。服务异常返回 no-store 503，不返回内部 SQL 信息。
- 现有有限期 member 类型按严格 UTC 起止校验；未来开始、空/非法日期、不存在的日历日期和未知类型不授予 VIP。不新增终身或多 grant 支持，不改正常兑换价格、周期与期限延长规则。
- Worker 与会员页面共用 safeReturnPath，拒绝站外、反斜线、控制字符、编码/多重编码、点段归一化后形成 `//` 的路径；保留正常站内路径、Unicode、查询和片段。音乐专用路由白名单仍留 M4。

## 未处理及授权边界

生产充值退款/拒付仍只冲回积分，未自动撤销 VIP。用户于 2026-09-09 确认人工核对明确关联后撤销；后续独立实现见 [退款人工审核](membership-refund-review.md)，未部署。不能按负积分封禁、猜测 FIFO、撤销所有历史期限。音乐下一阶段及真实 VIP 音频交付保持暂停。

没有改变 Creem 产品、价格、退款条款、小说/游戏单项权益或生产数据。新的退款来源关联/后台撤销流程应在规则确认后继续独立审查。本修复不是退款验收完成声明。

## 迁移与部署顺序

2026-09-09 已按用户授权完成生产备份、0036 迁移与 PR #118 同步部署；版本 837876c2-e6cf-44c3-a0de-50491e0d116b。用户随后报告真实兑换成功；不代表真实并发、重试或 Safari 已验收。以下顺序保留供后续维护参考，新退款审核迁移/部署仍需另行批准。

先备份并在隔离环境确认 0036，再执行生产追加迁移，再同时部署 Worker 与新版会员客户端。迁移缺失时兑换返回 503，不扣点；旧页面需刷新后才具备请求键。不得通过临时允许无键 POST 或退回旧扣点代码绕过问题。

回执与账单一起保留，不因一般缓存清理删除，否则旧键可能重新收费。回滚前暂停兑换，不退回无事务/无幂等版本；迁移为追加，不删除原会员、积分或会话记录。真实退款政策、真机 Safari 和生产多实例/故障演练仍需额外验收。
