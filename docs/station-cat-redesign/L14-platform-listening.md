# L14：歌曲页以平台收听为主

用户明确网站用于个人品牌和外部音乐平台引流，站内只展示已配置的试听、MV 等内容。本批在 PR #218 的首页主推简化和操作说明移除基础上，删除歌曲页的「确认完整收听权限」按钮及提示。

## 最终行为

- 四种语言的歌曲详情和目录主推卡均优先展示已核验的平台链接；收藏保留。只有存在有效公开试听配置时才出现试听按钮，MV/短视频仍走原资源校验。
- 浏览器不再准备完整音频、显示完整播放权限提示或会员解锁入口。网站会话和源地址解析器只接受 `preview`；过期页面数据中的完整播放字段无法启用它。
- 网站公开 DTO 保留 `fullPlayback` 字段以兼容旧字段结构，值固定为 `null`。站内旧完整播放恢复记录被忽略，不发请求、不显示播放器、不自动播放；已有记录原文保持到新试听选择覆盖。试听恢复、进度、收藏和近期播放继续使用原本的受限本地存储。
- 旧 `/api/music`、`/api/mobile`、账号与权益资料未修改。已有受保护的网站完整播放兼容接口仍保留原校验，页面已不再输出或调用它；本批没有撤销历史权益、删资源、远程迁移或部署。
