# L16 — 已封存测试作品的可恢复删除

旧后台的封存只清空播放指针，兼容目录继续列出歌曲。因此已经停止公开的测试作品仍会出现在新作品、发行平台和素材选择中。

本批支持显式的可恢复删除。`music_settings` 中的 `adminRemovedTrack:<UUID>` 是单个作品的删除记录；普通封存状态不等于删除。两套后台目录在分页之前排除删除记录，按名称搜索和直接读取同样不可编辑。新平台、推广、视频和网站编辑在读取及最终写入批次中检查记录，避免已打开的旧表单重新关联已删除作品。

`scripts/helpers/station-track-removal.mjs` 仅供经过授权的维护调用，不进入 Worker，也没有新增公开或管理 HTTP 写入口。调用者必须先保存目标记录并提供已核对的两个编辑版本。仅允许旧系统已封存、没有播放指针、网站尚未公开且没有平台、推广、视频、合集、首页、Campaign 或待执行发布任务引用的作品。删除标记、两个编辑版本的更新、审计和幂等回执在同一批次提交；状态或引用变化则全部拒绝。恢复使用相同 UUID，核对标记和当前版本后重新显示封存作品，不重新公开。

保留所有封存版本、原文件、素材权利、历史审计、上传记录和计费数据。没有删除触发器、放宽保留约束或释放素材配额；数据库结构、迁移账本及 R2 不变。公开路由继续根据原发布状态返回结果。本次生产目标另保存在本机私有操作记录中，源代码不硬编码测试歌曲名或编号。

验证覆盖精确排除、其他封存作品保留、直接读取、恢复、旧版本和已上线对象拒绝、并发引用、结果未知后的幂等重试，以及旧表单创建平台/推广/视频和编辑的阻止。实际生产操作与部署结果以本机私有验收记录为准，测试通过不代表已经执行删除。
