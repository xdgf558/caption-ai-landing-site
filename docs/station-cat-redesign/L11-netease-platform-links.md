# L11 · 网易云歌曲链接兼容

后台原先统一拒绝 URL fragment，导致从网易云网页复制的
`https://music.163.com/#/song?id=3438977672` 无法添加为发行入口。
现在统一的平台校验函数将这种地址保存为
`https://music.163.com/song?id=3438977672`，歌曲 ID 保持字符串原值。
发行平台表单也说明可直接粘贴原链接。

兼容范围为 HTTPS 的 `music.163.com` 根路径、无外层查询、fragment
严格匹配 `/song?id=` 加 1–20 位非零开头的十进制 ID。重复 ID、其他参数、
凭证、非默认端口、其他域名、其他 fragment 路由和编码歧义继续拒绝。
已有直达链接的处理保持原样；不添加外部请求、跳转解析或新的依赖。

保存和公开展示共用该校验，因此数据库、歌曲详情、首页和复制按钮使用
同一条直达地址。上线状态仍需发布管理员和实际核对时间；链接转换不会
自动确认发行、改变歌曲公开状态、设置首页主推或改写既有平台记录。

本机验证：

- 内容后台 71 项通过，其中真实 Access/D1/R2 运行时验证 hash 链接保存、
  幂等重放、人工核对要求、编辑员拒绝、公开读取和下架后链接消失。
- 平台 18 项、公开查询/封面 49 项、首页 19 项、staging 22 项通过。
- 实际后台入口处理器验证原始粘贴链接送到所选歌曲；安全地址及精度边界
  验证包含超出 JavaScript 安全整数范围的 ID，确保不改变歌曲编号。
- `npm test` 和正式首发构建通过；构建未使用空正文覆盖，产物为
  60 个 HTML、426 个文件。托管 CI 和生产部署事实另行核对。

本批无数据库迁移、生产歌曲/平台资料写入或生产开关调整。
