# 新建歌曲自动生成地址

新建歌曲的首屏只需填写作品标题和艺名。地址输入框默认隐藏，提交也不再携带手动 slug。服务端在创建新歌曲时使用 `track-<歌曲 UUID>` 作为地址，同时登记旧音乐记录和网站规范路由。

中文、英文或同名歌曲都不需要手动转换网址。编辑歌名不会重新生成地址；重复提交、并发重试和回执丢失沿用现有幂等记录。已有歌曲及其规范路由保持不变。旧客户端明确提供的地址继续按原规则校验，游戏介绍仍使用原有地址规则。
