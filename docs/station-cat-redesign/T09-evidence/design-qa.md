## 视口与截图

`viewport-measurements.json` 是最终源码的 DOM 读数：1371×996、768×900、601×844、390×844、320×740，DPR 为 1，documentWidth 均等于 innerWidth。桌面播放器约 100px；移动播放器约 129px，导航 64px，播放器底边与导航顶边一致。所有已显示播放器操作按钮均为 44×44。页面底部 padding 包含这些预留高度与额外 24px。

最终截图 `detail-desktop.jpg` 的原生捕获大小为 1371×912，少于桌面 DOM 高度 996，捕获范围没有覆盖桌面底部播放器，不能用该图宣称底部播放器可见；底部位置由 DOM 读数及两张移动截图核对。`detail-390.jpg` 为 390×844，`detail-320.jpg` 为 320×740，原生图中播放器、五项导航和控制按钮可见。`before-catalog.jpg` 文件名沿用初次捕获命名，实际是改动前的 T08 单曲页，432×585；`player-paused-390.jpg` 是修正切换覆盖层前的开发迭代图，保留作过程证据，不作最终交互通过依据。合成对照图采用等比例 contain 排列，不变形原截图。

## 交互与可访问性

实际 IAB 操作验证过试听开始、自然结束后静止、用户重播生成新 ID、暂停继续保留 ID、跨详情不选中浏览曲目、语言切换更新曲名、后退保留音频、刷新暂停无 src、匿名 VIP 完整播放拒绝。原生完整音频是 4 秒正弦波，试听是独立 1 秒正弦波；这些观测不能证明真实歌曲或商户权限。

键盘 Enter 核权仍静音，随后 Enter 主动播放；方向键调整进度保留 ID，Space 暂停并卸载完整源，Enter 关闭后焦点回到最后仍连接的触发按钮。播放器区域、滑块、关闭与播放标签随语言更新，状态区通过 role=status 提供文本反馈。没有运行 VoiceOver 或真实 iOS/Android，也没有模拟操作系统 reduced-motion；当前浏览器报告 false，新音乐壳切换动画始终禁用。

开发阶段发现换页后监听绑定过晚，以及原生 view-transition 快照层短暂截获立即点击；已改为 after-swap 去重绑定并禁止覆盖层接收指针。`browser-observations.json` 明确保留 `before-overlay-fix-immediate-click-did-not-pause` 失败观察，最后三条 `overlay-fixed-*` 证明最终源上同 ID 跨页、立即暂停且 src 为 null。较早语言、刷新和键盘观察归为开发记录，不冒充修正后全部重测。最终可见的 warn/error 控制台记录为空，见 `browser-console.json`。

NotAllowedError、旧 fetch 忽略 abort、快速 A/B/C、损坏与不可访问存储、账号通知由 24 个可控会话案例验证；没有用这些替代真实浏览器自动播放策略、会员到期或订单。核心及旧生命周期合计 147 项通过，日志可独立复算。自然结束恢复归零与 MP3 解码时长差异有专项回归，旧默认播放器恢复行为保持不变。

本批范围内已发现的交互问题均修复并验证。后续生产权限、全站壳接入、短视频互斥、安全区真机和会员到期回归仍属于相应后续任务，不是本批完成项。
