## 生产浏览器发现与修正

真实浏览器发现 Cloudflare 自动插入的可选统计脚本被游戏现有 CSP 阻止。运行端桥接此前把所有 `SCRIPT` 加载失败都当作游戏失败，父页立即移除 iframe，因此真实游戏尚未发出 `ready` 就被误判为失败。本机无该注入，原夹具未覆盖这一条件。

本 PR 将失败判定收紧为运行时异常或同源 `/games/cat-life/` 下的必需脚本加载失败。可选第三方及非游戏路径脚本失败不会宣布失败，也不会宣布启动成功；仍必须收到实际运行端的 `ready`。不放宽 CSP，不启用统计，不改变消息来源/实例核对、存档、退出等待或 iframe 边界。回归覆盖被拦截的可选统计、同源非游戏脚本、必需脚本和运行时异常；相关 34 项通过。

按已准备的故障方案，**2026-10-12 00:05:19 新加坡时间** 已切换到 `e85f8c41` 关闭内容维护版本。实际核对首页为维护 503、旧小说和正文 API 为 410、原游戏 `/games/cat-life/` 及账号/存档游客服务仍可用。没有恢复业务数据。Wrangler 刷新认证后使先前只读 token 失效；用新只读客户端确认已成功的版本，没有再次部署。

修复头的完整托管 CI、最终冻结包、恢复新版、真实游戏 ready/退出、性能和最终 HTTP 结果继续补在同一个 PR。当前维护观察不等于最终新版验收。
