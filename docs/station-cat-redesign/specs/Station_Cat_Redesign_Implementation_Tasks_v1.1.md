# Station Cat 网站改版实施任务清单

版本 v1.1
配套基线 Station_Cat_Website_Redesign_Development_v1.1.md
适用对象 开发者 Codex 与验收人员

本文将开发文档拆成 22 个可交付任务，说明依赖、实现范围和验收证据。改版以个人品牌推广为主要目标，大部分歌曲在各音乐平台发行；网站提供官方作品展示、推广配置与平台导流，站内试听按后台专门模块设置。复用现有账号、支付、媒体与存档能力。本清单中的任务编号、PR 分组和文件路径均为实施建议，实际代码位置在 T01 盘点后确定。

原开发文档定义产品范围，本清单安排执行顺序。发现冲突时先定位现有代码和业务数据，记录差异；涉及已生效权益、存档或收费规则的冲突保留当前行为，其余工作仅在当前已获授权任务的范围内推进，不跳过逐项审查顺序。没有仓库检查结果，不给出确定工期。

执行顺序以用户于 2026-10-05 确认的一任务一 PR 为准：按 T01 至 T22 逐项执行，完成当前任务后提交可审阅 PR，由用户审查通过后才进入下一项。R0–R7、S0–S4 只说明功能分组，不授权连续推进、跳过任务、自动合并或生产发布。当前任务状态见 [执行记录](../README.md)。

## 1 工作成果与完成标准

任务状态采用未开始、实施中、待验收、已完成和受阻。已有文档和空页面只能证明准备工作完成。功能完成需要真实数据路径、错误处理和对应验收证据，未执行的测试标为未验证。

每个 PR 描述应写明用户触发动作、实现后的行为、验证方式、迁移影响与回退方式。测试结果带实际命令、环境及结果；真机结果带设备和浏览器版本。截图用于界面核对，权限和存档验证需要独立证据。

建议在仓库 docs/station-cat-redesign/ 下保存现状报告、路由迁移清单、权限矩阵、事件字典和验收记录。若仓库已有文档约定，沿用已有目录。本文不要求把这些建议文件提交到不存在的仓库。

## 3 S0 现状与边界核对

### T01 仓库与运行方式盘点

依赖 无。读取 AGENTS.md、项目文档、包管理锁文件、构建配置、路由和服务入口。确认本次目标仓库与 wwwstationcat.org 的关系，记录实际分支和提交，避免误改同名项目。

定位框架、数据库、CMS、鉴权、媒体存储、支付回调、语言前缀、游戏启动、存档读写和部署方式。输出现状报告，逐项区分已实现、配置中、仅有文案和暂时无法确认。每个结论引用真实文件及关键实现位置。

完成证据为现状报告与实际可执行的构建、测试命令。无法访问服务凭据时记录受阻检查，不编造运行结果。此任务不修改生产配置。

### T02 路由与业务依赖清单

依赖 T01。通过路由定义、站内链接、sitemap、下载页和客户端调用点，列出旧栏目及全部语言版本。每条记录包括旧路径、内容类型、调用者、拟定动作、替代地址、保留理由和验证结果。

明确区分公开作品页与服务接口。授权、支付回调、账号删除、历史订单、余额、售后支持和游戏运行地址单列。外部推广链接无法完整获取时标记清单缺口，不能断言已盘点所有外链。

完成证据为逐地址清单及游戏运行地址保留方案。覆盖原验收 A17，实际 HTTP 状态检查在 T20 完成。

### T03 权益存档与素材核对

依赖 T01。建立游客、普通账号、现有会员及历史购买者的权限矩阵，记录站内音频模式、收藏位置、订单访问、积分用途和存档行为。用隔离测试账号和测试存档核实，不在生产存档上演练覆盖。

建立最小上线素材清单：一首真实主推歌曲、封面与真实平台发行状态；推广模块开启试听时提供独立可公开试听文件，未开启时不列为必备素材；已上线平台录入核验后的链接。有已发布短视频时录入真实素材；提供一款可运行游戏及真实截图。没有视频时隐藏区块，没有发行链接时保留准确状态。

完成证据为权限矩阵、存档格式记录和素材缺口表。音乐会员规则未知时保留旧校验，实现其他页面工作。对应 A04、A13、A14。

## 4 S1 页面与内容基础

### T04 视觉变量与导航组件

依赖 T01、T02。前端设计时先直接调用 product-design:index 与 product-design:ideate，提供 3 个具有明显差异的可视化 UI 模板，说明首页布局和手机适配思路，等待用户选定后再进行前端视觉编码。选定前仅处理当前任务中的无依赖准备，不跳到其他任务。沿用现有样式体系，并按选定模板建立颜色、字体、间距与组件规范；深蓝灰、米白和暖金仅为初始参考。顶部与手机底部导航只保留首页、音乐、游戏、我的对应入口，语言规则保持一致。

将导航、迷你播放器和安全区域的底部占用统一计算。提供键盘焦点和可读名称。游戏运行布局支持隐藏网站控件。非内容性的法律与支持页面保留。

完成证据为 3 个可视化 UI 模板、用户选定记录、按所选模板实现的桌面及手机截图、键盘操作记录和底部遮挡检查。对应 A01、A16、A22。

### T05 首页与首页配置

依赖 T03、T04。实现个人品牌首屏、主推歌曲、精选歌曲、最多四张短视频卡片、主推游戏和页脚。主推歌曲取自推广模块有效配置，平台为主要收听入口，试听按钮按启用状态显示。所有区块根据实际公开状态显示，无有效引用时隐藏或给出明确空态。

首页配置采用稳定对象 ID，提供发布版本。先通过现有配置机制接入，后台编辑在 T16 完成。首页按钮可直接进入对应作品，不额外经过目录。

完成证据为有完整素材、缺视频、缺平台入口三种状态截图；首次访问保持静音。对应 A01、A03、A20。

### T06 兼容数据模型与迁移

依赖 T01、T03。将 Track、PlatformLink、Clip、Game、HomeConfig、PromotionTrackConfig 等逻辑模型映射到现有系统，优先扩展已有结构。提交字段对应表，写明复用字段、新增字段、默认值、空值含义和唯一约束。

稳定 ID 不变。slug 别名用于旧地址重定向。资源、网站发布时间和平台发行状态分开存储。业务数据迁移具备幂等性；新字段允许旧程序继续运行，不在此 PR 清理旧表。

完成证据为隔离环境迁移、重复执行结果及旧读取回归。回退说明保护迁移后新增数据。对应 A14、A15、A18。

### T07 公开查询与资源权限

依赖 T06。实现歌曲目录、详情、已发布视频、游戏摘要和播放资源查询。采用显式公开字段映射，草稿及未发布对象不进入公开查询、相关作品和首页引用。私有完整音频的地址、存储键与凭证不进入公共响应。

推广模块开启试听且资源有效时，游客查询返回独立公开剪辑资源；未开启时不提供试听承诺或空播放器。受保护完整音频继续调用真实会员校验，推广配置不改变完整资源权益。列表采用稳定排序与有限分页。错误保留鉴权、权限、限流和暂时不可用的区别。

完成证据为游客、授权用户、失效会话、草稿对象和服务故障的接口验证。检查缓存不会把授权完整资源响应共享给游客。对应 A04、A14、A15。

## 5 S2 音乐与游戏核心路径

### T08 音乐目录与单曲详情

依赖 T04、T07。实现标题和艺名搜索、默认排序、最新发行排序及分页。单曲页按封面与播放、平台选择、短视频、MV、歌词、介绍和相关作品组织。游客可直接访问推广落地地址。

标题和歌词转义，缺少字段不显示空装饰区。搜索无结果提供清除条件，查询失败提供重试。收藏和评分沿用真实存储方式及提示。

完成证据为真实单曲、后台开启公开试听、未开启试听、无已上线平台、搜索无结果、请求失败和长标题场景。A02 按推广配置分别验证，不能要求全部歌曲均提供站内试听。对应 A02、A15、A16。

### T09 音频播放器与请求竞态

依赖 T07、T08。保留单一网站音频实例，管理曲目、请求版本、播放状态和 playback_id。切歌时取消旧请求或忽略过期结果。暂停后再次继续同一次播放不重复产生开始事件。

区分首次播放、重播和切歌。自然播放结束后主动重播创建新 playback_id；拖动进度或缓冲后恢复沿用当前 ID。刷新可恢复曲目选择，保持暂停。

完成证据为快速切歌、受保护资源失败、播放被阻止、暂停继续与刷新场景。对应 A04、A05、A09。

### T10 发行平台入口与降级

依赖 T07、T08。平台入口采用后台真实状态，只有 live 且 URL 已核验才可点击。网易云、汽水与 Apple Music 使用相同数据接口，支持后续扩展。排序由运营配置或用户主动选择决定。

优先普通 HTTPS 链接。统计发送失败不影响点击。仅在已有可靠接入时提供 App 唤起；失败时保留 HTTPS 和复制入口，不以倒计时跳转认定 App 已打开。

完成证据为未发行、已下架、无适用链接、站内统计故障及内置浏览器场景。对应 A03、A10、A11、A21。

### T11 短视频与 MV 播放

依赖 T07、T09。实现关联素材封面、时长、用户点击播放、inline 模式和按需加载。播放视频前暂停网站音频，关闭弹层立即停止视频，焦点回到触发位置。

先落实自托管或现有受控播放器，跨域不可控嵌入需明确互斥策略。Apple Music 嵌入保留为 P1。外部素材受阻时提供原链接，播放器失败显示重试。

完成证据为音乐播放时启动视频、连续切换视频、关闭弹层、错误素材和键盘操作。对应 A06、A09、A22。

### T12 游戏作品页与存档入口

依赖 T02、T03、T04、T07。实现游戏目录与介绍，展示真实截图、支持设备和存档说明。读取现有存档检查结果，以有效兼容存档判断继续入口；不可访问存储、损坏或版本不兼容均不得默认为空存档并覆盖。

缺少安全存档检测接口时，记录新入口的具体受阻原因并接通安全检查，禁止将错误状态当作空存档。开发期间保持现有入口可用；新版上线后旧公开入口关闭，不能以保留旧介绍页代替新路径验收。有效游戏运行地址与存档服务保持稳定，云存档登录要求继续由现有权限处理。

完成证据为新游客、有效存档、存储禁用、损坏存档和不兼容格式。对应 A13、A14、A19。

### T13 游戏运行与媒体协调

依赖 T09、T11、T12。进入游戏前暂停网站音视频，隐藏网站导航与播放器。加载失败与退出恢复网站布局，音乐保持暂停。重试清理旧实例和旧事件监听。

运行端若能回传就绪，消息校验 origin、source、game_id、launch_id，拒绝来自其他窗口或旧实例的消息。启动超时时间依游戏实测记录配置，超时不擅自删除存档。

完成证据为加载成功、失败、快速返回、反复重试与伪造消息。对应 A07、A08、A13。

### T14 我的与历史服务回归

依赖 T02、T03、T04。在我的保留账号、现有订阅、订单、余额、已购权益、存档和真实收藏入口。退出旧内容频道不影响服务操作。明确本机保存与云同步状态。

不在本任务修改付款价格、权益期限、退款规则或账号删除协议。已发布客户端依赖的服务页面继续可达。

完成证据为权限矩阵逐项回归及关键服务地址响应。对应 A14、A19。

## 6 S2 内容运营后台

### T15 上传与资源校验

依赖 T03、T06。复用现有上传与对象存储，区分上传中、校验中、就绪和失败状态。验证格式、时长、大小、完整性及视频尺寸，试听文件与完整文件分开引用。

上传使用版本资源键，失败可重试，重复确认不生成重复资产。管理权限在服务端校验。存在公开或历史引用时禁止物理删除。

完成证据为合法媒体、损坏文件、超限文件、上传中断、重复确认和越权操作。对应 A04、A15、A18。

### T16 编辑发布与内容回退

依赖 T05、T06、T15。在现有后台提供歌曲、推广歌曲专门配置模块、平台链接、素材、发布记录、游戏介绍和首页配置。推广模块管理推广启用、主推排序、独立公开试听开关与资源、平台入口、关联视频及 Campaign；首页读取有效推广配置。网站作品页公开与外部平台发行分开管理。内容编辑和发布权限映射到当前角色，不另建账号体系。

发布前校验资源状态、公开关联和权利登记；推广试听启用时必须有就绪的独立公开资源，未启用时不要求提供站内音频。平台链接只使用已核验的真实状态。使用 revision 处理并发修改，记录版本与操作人；下架或停止推广后失效引用不得残留在首页或缓存。定时发布失败保留可编辑状态及错误原因。

完成证据为编辑至发布流程、并发发布、下架、定时任务失败、内容回退、开启试听但资源未就绪被拒绝，以及关闭试听或停止推广后的公开响应与首页缓存更新。对应 A15、A18、A20。

## 7 S3 推广与统计

### T17 Campaign 与链接生成

依赖 T08、T16。后台从推广歌曲专门模块的有效记录创建与歌曲、素材关联的 Campaign，生成推广地址及二维码。UTM 参数必须映射已登记记录，旧 src 参数仅解析明确映射。未知参数归为 unknown。

区分访问会话和归因上下文。新合法 Campaign 可以改变后续事件的归因上下文，不修改已入库事件。歌词页面与内部浏览不自动继承原始 URL 全部查询串。

完成证据为同素材不同渠道、旧参数、直接访问、恶意超长参数与不同 Campaign 连续访问。对应 A02、A11。

### T18 事件接收与去重

依赖 T09、T10、T11、T13、T17。实现 event_id 去重、事件类型验证、批次上限和限流；只记录真实操作确认，错误或缓冲不产生播放开始，未得到运行端消息不产生游戏就绪。

统计口径以主开发文档为准：preview_qualified 在前台实际累计试听至少 10 秒或试听结束时触发，同 playback_id 一次；结束由媒体实际 ended 确认，拖动到末尾的操作本身不作为结束事件。clip_complete 要求媒体实际 ended 且未跳过主要内容。累计播放时间排除暂停、等待、拖动跳跃和隐藏页面时间。本清单不另设 90% 阈值，事件字典与主文档保持一致。

验证隐私同意、禁用存储和网络失败的降级。匿名会话不可持久化时采用内存 ID，标记统计范围限制，不承诺跨页面或跨设备唯一用户数。播放核心路径不依赖统计成功。

完成证据为重复上报、暂停继续、拖动到结尾、页面隐藏、限流及统计拒绝。对应 A08、A09、A10、A12、A19。

### T19 聚合与运营报表

依赖 T18。展示访问、试听开始、有效试听、平台点击、视频及游戏指标，支持按歌曲、渠道、Campaign、素材和平台筛选。明确指标时间窗和分母。

推广转化率以单曲访问记录及对应会话做关联，已经出现 platform_click 的有效单曲访问会话只计一次；事件跨歌或跨时间窗不强行混入同一分母。缺少关联的事件可以计入独立总次数，同时标记不能计算转化率。

外部播放、曝光数据人工导入时保存来源与更新时间，缺失显示暂无数据，不用零值代替。外站点击不命名为平台播放。没有运行端确认时游戏就绪显示暂无数据。

完成证据为固定小样本人工核算与报表一致、重复点击、空数据和跨窗口场景。对应 A08、A10、A12。

## 8 S4 迁移与交付

### T20 旧地址退出与搜索配置

依赖 T02、T08、T12、T14、T16。实现并在隔离环境验证逐地址关闭规则，保留内容迁到对应新地址，退休页面返回真正的 404 或 410，服务依赖持续可用。同步修改站内链接、sitemap、canonical 和语言关联。生产切换在 T22 新版开发完成并上线后执行，直接关闭被替代的旧公开入口；旧页面不作为常态回退入口并行公开。有效游戏运行地址、存档、账号与支付服务持续可用。

备份与引用导出先完成，代码移除与生产数据物理删除分开处理。本期不执行生产数据物理清理。旧栏目退出不能把授权和支付服务一并关闭。

完成证据为隔离环境清单自动检查报告、抽样 HTTP 响应、旧游戏存档回归和索引配置检查；上线后的旧入口关闭与生产响应在 T22 核验。对应 A14、A15、A17。

### T21 核心回归与设备验证

依赖 T01 至 T20 的相关功能完成。对照原文档 A01 至 A22 建立证据表，检查真实媒体播放、历史权益、存档、管理权限、公开响应和迁移状态。A17 在上线前采用隔离环境预验，上线后由 T22 记录生产关闭确认；两类结果分别标注。主文档规定的统计口径纳入对应事件测试。

使用仓库真实测试命令，不要求为了简单样式变化新增重复测试。设备和网络验证覆盖手机浏览器、内置浏览器、桌面与键盘；缺少真机环境时记录未验证项，不把浏览器模拟写成真机通过。

完成证据为测试报告、截图、实际环境与剩余受阻项列表。必需核心项失败时，修复后重跑对应检查。

### T22 灰度与回退准备

依赖 T20、T21。准备可切换前端、兼容数据库、内容配置版本、备份恢复验证和监控指标。模拟一次回退，确保新订单、新存档和迁移后写入保留。

形成上线步骤及实际执行条件。新版开发完成并上线后，立即执行 T20 已验证的旧公开入口关闭规则，核验 404、410 或对应内容重定向；旧前端只保留为受控回退版本。账号、历史权益或存档异常触发停止扩量；统计故障可单独停用统计。生产部署与旧入口关闭依实际授权及仓库发布流程执行，准备完成、部署完成与关闭核验分别记录。

完成证据为可审阅版本、迁移和回退命令说明、演练结果以及上线检查表。本文本轮交付为任务材料，不代表生产网站已经修改。

## 10 第一批开发交付要求

第一批先完成 T01 至 T03，输出真实文件位置、权限矩阵和迁移地址清单。确认身份与权限边界后，调用 UI 设计技能提供 3 个可视化模板；用户选定后推进 T04、T05 的页面与导航实现。T06 的兼容模型设计等无依赖工作可继续进行。遇到素材或业务缺口时保留准确空态，继续不依赖该缺口的工作。
