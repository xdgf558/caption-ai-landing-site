首页 Worker 渲染和 Astro 模板现共用音乐封面地址选择：主推使用 display 并尽早加载，精选使用 card 并保持懒加载。静态夹具地址保持有效；游戏截图与视频海报不添加音乐封面尺寸参数。沿用原有受控接口，仍先核对公开状态、权利与对象身份，缓存命中通过重新验证返回 304。没有新增公开原始文件路径。
