## 修订与原因

| 失败用例 | 原因和修订 |
| --- | --- |
| 旧游客首次云上传预期 42、实际 200 金币 | 旧 schema 0–2 的 `cats: []` 有既有补齐迁移，但新只读检测拒绝后，登录用户被判为缺少相容游客来源。恢复该旧格式检测，加载仍由既有迁移补齐猫咪并保留 42 金币及音量。缺失猫字段、schema 3 空列表和其他损坏状态不放行。新增实际 saveSystem 的只读检测、迁移和首次保存回归。 |
| 游客伪造高级房间时 state 为 null | 旧夹具省略猫和库存结构，按 T12 合同属于不完整存档。补齐必要字段，只伪造本用例需验证的房间值；等主页就绪再核验免费外观。没有放宽高级权益或不完整存档检测。 |
| 缓存当前账号的离线装扮没有启动 | T12 已要求缓存会员先确认会话，完全断网应停止运行。装扮离线用例限定为先验证同一账号、装扮服务离线，保持禁止兑换；另增会话不可用时拒绝启动、保留会员原文、无新游客槽位或云写入的检查。缓存仍不作为身份授权。 |
| 照顾夹具重载出现 SAVE_BLOCKED: changed | 夹具在游戏读取后直接改 localStorage，触发比较保护。改用实际 saveSystem 保存夹具，同步已观察基线；另增真正外部改档后退出/重载的检查。运行端捕获已经触发保护的 saveStatus 拒绝，防止预期保护产生未处理生命周期错误，原写入仍被拒绝；其他异常照常抛出。 |

新增用例交给现有托管浏览器步骤执行，没有绕过、删除或跳过原用例。未在用户本机调用 Playwright CLI。云端接口、旧购买权益、费用、账号服务和双开关接管规则没有改写。
