## 操作、动画与焦点

实际 IAB 标签 5、127.0.0.1:4208 的本地编译 Worker/D1/R2：四语言首页无 audio/video，点击已选短视频后原生播放；30 秒自然结束显示所属歌曲，未配置可用平台时没有平台入口；Escape 结束动画后回到同一个首页卡片。

最终歌曲页记录音频暂停前 paused=false、readyState=4、currentTime=0.525267；启动视频后音频 paused=true、currentTime=0.573811，并且只有一个原生 video。连续短片/MV切换没有累积媒体。关闭开始立刻移除 video，150ms 动画期间 dialog 仍打开且焦点在关闭按钮；动画完成后 dialog 关闭，焦点回到具体故障片段的触发按钮。即时停止和动画完成分开记录，不把前者声称为已恢复焦点。

故意损坏片段触发真实浏览器解码 error，出现重试及合成原链接，重试后依旧准确显示失败，不伪造播放。HTML Tab/Shift+Tab 边界在弹层内，关闭/选择/重试可见且可操作。播放器沿用 transitions-dev 的 06-modal CSS，开启 250ms、关闭 150ms；减少动画时同步关闭，媒体清理不等待动画。

Node 的可控 DOM/实际 T09 会话核对晚到握手、play promise、close 事件、重开计时器、新音频意图、pagehide/disposal、卡片消失焦点与未支持 dialog；这些不冒充实机浏览器证明。浏览器没有通过 evaluate 写 DOM、网络、存储或权限制造结果，合成原链接没有点击。

当前标签 warn/error 控制台为空，见 `browser-console.json`；最终与早期观察分别记录于 `browser-observations.json`。274 项最终源码本地测试、主构建、四语言独立首页构建及 staging 资源核验通过，见 `verification-summary.json`。空正文构建不是生产包；PR 实际头托管 CI 另行核对。
