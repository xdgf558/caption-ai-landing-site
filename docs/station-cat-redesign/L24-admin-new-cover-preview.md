# L24 新上传歌曲封面预览

《把晚安往后放》的公开原图为 177×177 PNG、67,878 字节，读取正常，但源指纹没有进入部署时的 display manifest。L10 的后台接口只接受清单内的 card，所以文件已保存的歌曲仍显示“预览暂不可用”。

后台继续优先读取现有静态 card。缺少 card 时，在现有 Access、后台开关、D1 素材状态/清理记录和条件 R2 对象身份检查之后，读取并核对原件字节数、SHA-256 与图片结构，使用已有 Photon 依赖生成最长边 192 像素的 WebP。输出最多 192 KiB，保持透明度。解码延迟到真正需要时，不在正常页面请求启动时运行。

请求内输入限制为 5 MiB、4,194,304 像素，与现有 Worker 图片解码预算一致；更大的原件仍需发布生成器提供静态 card，不能无上限在 Worker 内解码。读取有五秒截止和读取次数限制，失败时关闭流，解码后释放 WASM 图片。不存在原图回退、额外 R2 副本或 D1 写入。公开图片接口的既有行为保持不变。

生成结果使用源指纹和算法版本作为 ETag，浏览器保持私有、每次重新验证。304 同样先通过当前管理员和素材身份检查；不依赖 Cloudflare Access 前方不可用的 Cache API，不公开私有封面。显式“重新核对工作区”会重试失败预览，健康的列表图片继续保留，普通选择、搜索和分页不触发全列表重载。

回归使用真实 workerd、临时 D1/R2、编译 WASM 与签名 Access 夹具，覆盖清单外 PNG/JPEG/WebP 的 GET/HEAD/304、未公开封面、身份失效、服务关闭、素材未验证和对象替换/删除，以及畸形输入、哈希不符、截断和解码尺寸上限。前端入口覆盖失败图片重试及健康图片节点复用。staging 只放行 `adminThumbnail.js` 中这一处固定的 Photon 延迟导入，其余动态导入仍拒绝。

部署仅更新代码与静态包，沿用完整生产配置；不重新上传或发布歌曲，不修改已保存的平台链接、服务开关或数据库结构。部署证据保存在本机私有发布目录。
