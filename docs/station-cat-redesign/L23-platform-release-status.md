# L23 — 发行平台列表显示外部发行状态

发行平台页原先复用网站作品的 `published` 状态，保存平台入口后列表也未重新读取，导致用户看到“已公开”，无法判断外部链接是否已上线。

现在 `/tracks` 列表返回独立的 `platformStatus`，发行平台页的“发行状态”列和编辑器徽标读取该字段。作品内容页继续使用网站公开状态。列表查询一次读取每首歌曲最多 26 条平台记录（正常上限 25），没有逐首请求；搜索、分页与管理员鉴权保持原路径。

| 平台记录 | 列表状态 |
| --- | --- |
| 无记录 | 未添加 |
| 至少一个有效、已人工核对的上线入口 | 已上线 |
| 没有有效上线入口，存在未核对或异常记录 | 待核对 |
| 其余记录中有待发行入口 | 待发行 |
| 其余记录中有暂不可用入口 | 暂不可用 |
| 全部已下架 | 已下架 |

区域限定入口按其登记地区判断，不以管理员所在地区决定整首歌的发行状态。保存后从服务器重新读取状态并更新对应行，保留未变化的图片节点；失败不乐观标记上线。写入回执不明仍保留原操作与幂等键。已确认保存但后续读取失败时显示“待核对”，提示重新读取，不留下可重复添加的旧表单。

网易云 `https://music.163.com/#/album?id=398968221` 会规范为 `https://music.163.com/album?id=398968221`，保留专辑类型和原 ID。歌曲 hash 地址仍支持。未知来源、额外参数、凭证、重定向和模糊 fragment 继续拒绝；此次没有自动填写真实核对时间或写入生产歌曲资料。

验证覆盖实际 HTTP 处理器、数据库迁移夹具、控制器与入口事件：首次保存、更新、下架、重新读取、页面重开、网站状态独立性、多平台聚合、区域与未核对状态、搜索分页、冲突、回执丢失及读取失败恢复。原生 Worker/D1 回归验证专辑地址保存及公开响应；浏览器在临时 D1/R2 中操作合成歌曲，确认“未添加”变成“已上线”，重新读取后保持一致。
