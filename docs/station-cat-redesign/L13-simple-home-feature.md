# L13：首页主推一次更新

本次把首页主推收敛为「选择已公开歌曲 → 更新首页」。首页配置使用独立表单，常用项只保留主推歌曲、主推游戏和更新按钮，精选歌曲与短视频放在折叠区域。显示当前已发布选择、未更新修改和更新结果，提供直接查看首页的链接。

## 发布行为

新增受原 Access、同源写入校验、内容后台开关和 publisher 角色保护的 `POST /admin/api/music/site-content/home/:id/apply`。客户端发送首页编辑版本、来源修订和完整选择；继续使用原操作键与恢复日志。确认成功后的读取失败会明确提示「首页更新已确认，但工作区刷新未完成」，不把已确认写入描述为发布失败。

主页与缺失的基本推广在同一个 D1 batch 中发布，连同原操作回执、审计和版本比较一起提交。任何一个关联不合法或后段写入失败，都不会留下只发布推广而没有更新首页的状态。关联保护参数仍有限额，不展开无界图。

已生效、已启用的推广完全复用，包括原已公开试听设置。尚无有效推广时，创建新的基本公开修订：启用推广、试听关闭、无视频，采用此歌曲当前已上线且人工核验的合法平台链接。已有推广草稿原文及草稿指针保留，不公开其中尚未审核的试听或视频修改。首页的即时更新取消旧首页定时任务；需要生成基本推广时，同时取消该推广的旧定时任务，相关任务 ID 写入审计。移除首页歌曲只更新首页引用，不下架歌曲或撤销该歌曲原推广。

公开作品、封面/歌词权利、当前 R2 对象身份、平台归属、公开游戏及原完整播放权限仍按既有发布校验处理。公共读取仍只接受当前公开且有效的推广和首页，不读取草稿；后续对象/权利撤销仍可让该项退出公开结果。D1 和 R2 校验没有跨系统事务保证。

新增 `GET /admin/api/music/site-content/home-tracks` 按网站当前公开歌曲分页，直接读取公开版本标题，不依赖旧音乐生命周期或推广登记。共享下拉分页保留当前选择，并处理另一个选择框已读完共享游标的情况。
