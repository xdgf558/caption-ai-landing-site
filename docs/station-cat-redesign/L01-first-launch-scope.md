# L01 首次正式上线范围与关闭旧内容

用户在本聊天确认首次上线“先上线品牌与游戏内容，音乐主推留空，试听和视频关闭；之后在后台配置”，并追加“旧小说等其他内容全部关闭掉”。本文件据此调整 T20/T22 的旧章节、旧专辑及产品服务页例外。继续采用一批一 PR、用户审查后合并的流程。

## 首发内容

五项导航仍为首页、音乐、游戏、会员、关于。保留已选定的温柔小站设计；音乐目录可以呈现空态，不选择旧“最新免费”、示例歌曲、平台链接或合成视频。游戏介绍使用 `cat-life-game`，实际运行目录仍是 `/games/cat-life/`。通用站点隐私、条款、联系、账号与积分服务继续提供。

[首发范围文件](../../ops/station-first-launch.json)记录这次决定。[内容检查 SQL](../../ops/station-first-launch-content-check.sql)只读核对：无公开新音乐、推广或视频，只有实际 Cat Life 游戏及其首页引用；首页主推音乐、精选、视频和旧动态引用全部为空。公开计数匹配不能证明素材权利、R2 就绪、身份、性能或 HTTP 验收，必须分别验证。首发后可通过已有后台配置新作品；本范围文件限制的是这次切换，不能替代后台发布权限。

## 关闭合同

新增 `STATION_LEGACY_CONTENT_CLOSED`，默认关闭；五个页面组成开关全部开启且该开关开启后，才应用这次收紧。关闭态或部分启用仍交回原处理器，不提前改线上。

| 范围 | 首发切换后的行为 |
| --- | --- |
| 旧小说章节及 `works` 书签别名 | 已存在章节直接 410，历史购买者也不进入旧阅读页；不存在仍 404，无法核对时 503 |
| 旧小说目录、Signal、开发日志及旧产品介绍 | 既有 T20 的已知 410、未知 404；Cat Life 旧介绍映射到新游戏介绍 |
| 旧产品下载、Android、支持、隐私和条款页，以及旧 `/downloads/` 文件地址 | 410；通用站点政策与联系地址不属于这组旧产品页 |
| 旧内容列表、正文、媒体、小说访问/价格/评论/解锁/阅读事件与旧网页评论 API | 410 JSON，`private, no-store`，不读内容或登记新解锁 |
| 旧专辑 `?collection=` 播放器 | 合法旧入口 410，不返回旧播放器 |
| 旧 UUID/slug 音乐分享 | 已有新发布实体则由新路由映射；仅有旧歌曲且无新发布实体时 410，未知仍 404 |
| 小说付款入口 | 拒绝小说购买、打赏以及带旧系列的积分包；共享入口的通用 Station Points 产品保留原流程 |
| 账号、会员、历史订单查询、商户回调、游戏云存档、原生 `/api/mobile` 与 AASA | 保留原处理器；不删除订单、余额、历史权益、作品或存档 |

新站页面中的旧章节、产品附属页和下载链接也被移除。旧 Signal 的新定时采集停止，已有队列仍由原处理器处理；这不宣称取消已发出的请求或共同事务。本批不更改游戏的云写入并发、浏览器存档窗口、1 秒退出等待、同源 iframe 或上传配额边界。

## 专用候选包

```sh
npm run build:station:first-launch
npm run test:station:first-launch
```

本机预览可运行 `node scripts/serve-station-first-launch-preview.mjs`，地址 `http://127.0.0.1:4224/`。只接受 loopback GET/HEAD，禁止管理员和认证路径、外发网络及真实登录；临时库中的游戏截图与权利字段是夹具，不是已发布的生产后台记录。

构建到 `.generated/station-first-launch-assets`，与原 `dist` 分开；拒绝 `ALLOW_EMPTY_SERIAL_CONTENT`。它保留已跟踪的旧付款和受保护正文兼容清单，**不重新生成空价格/正文指针**，不上传或删除 R2 内容。旧展示 HTML、旧首页/播放器、旧静态跳转与 sitemap 不进入候选包。保留真实游戏文件、供 Worker 使用的内部模板、管理员页面和通用账号/政策服务。文件大小、SHA-256 与兼容清单哈希写入独立 manifest；实际 Worker + Miniflare Assets 使用这个候选包测试，而不是只检查源码路径。

生成首次上线配置提案时，从经审核的完整私有生产基线派生，保留旧绑定及变量，将 Assets 设为 Worker-first，并一起开启五个组成开关和旧内容关闭开关：

```sh
node scripts/build-station-first-launch-config.mjs \
  --baseline "$station_reviewed_config" \
  --baseline-sha256 "$station_reviewed_config_sha256" \
  --output "$station_first_launch_config"
```

输入和输出必须在仓库外，输出 0600、禁止覆盖。它不部署或确认生产状态；索引、上传、内容后台、定时、Campaign、采集和报表开关保持关闭，待各自生产 schema、Access、权限及保留合同验收后配置。不能将本批合成 dry-run 基线当成生产配置。原 T22 关闭态生成器目前覆盖 16 个 Station 开关，新增的一个是旧内容关闭开关。
