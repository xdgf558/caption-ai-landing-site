# L07 — 清晰编辑台与历史歌曲恢复

用户选择的是本轮最后展示的第 3 张「清晰编辑台」，不是此前首页模板的编号。选定图保存于 `L07-evidence/selected-admin-design.png`。本批沿用一任务一 PR；新界面尚未部署。

## 新后台

`/admin-v2/` 和既有 `/admin/music/content/` 共用作品工作区。左侧为站点导航，中间为歌曲、游戏和视频列表，右侧编辑资料、查看素材与权利状态。搜索、类型筛选、独立分页游标、新建、草稿、预检、发布、下架和版本回退沿用既有内容控制器、原操作键、编辑版本与服务器核权。

`/admin/music/media/` 和 `/admin/music/` 进入同一壳。素材导航携带作品编号和用途；只有已读取且匹配的草稿可预选，找不到时保持空选择，不代选另一作品。完整音频、试听、封面和歌词继续使用原音乐工作区，深链接直接打开素材标签。上传记录区分技术校验与权利登记。图中的 500 MB 与混合格式限制没有写入产品。

原账号、订单、权益、游戏商品和通用审计工具移至 `/admin-v2/services/`，接口与控制器保留。小说、文章、导入、简报、阅读统计、旧评论与反馈编辑器保留为隐藏且 inert 的兼容结构，入口不展示，启动不读取旧内容列表或收费默认值；服务标签有显式白名单。没有删除存量数据或改账号、订单、存档接口。

列表的素材状态是当前关联记录的提示，不是 R2 现场验证。新图片查看路径仅接受已验证的海报和游戏截图，每次经现有 Access 与内容开关检查，核对对象身份后私密流式返回；它不提供音频、视频或公开授权。封面仍通过原管理资源接口。错误类型的资源不会被当作缩略图自动下载。

定时、Campaign 与报表保持原开关。报表入口在未启用时显示关闭状态。修复权利/平台视图没有 jobs、revisions 数组时的控制台错误；空操作说明会在解除临时锁定后取得焦点。手机导航关闭时不可获得焦点，打开后保留焦点范围，Escape 可退出。

生产活动版本仍为 `1f3fb556-0b91-4946-b524-0ebe83223619`，100%；绑定与原版本一致，MUSIC_DB 账本 18 份。新后台代码尚未进入生产。审计复核和匿名 HTTP 的完成时间分别为证据 JSON 中的 UTC 时间，新加坡时间为 UTC+8。

## PR #214 审查修订

审查基线为 `6095729faa150502a367fb6febcc85ac43feec6e`。该头的托管 CI 失败属实，先前 85 项局部回归和视觉 QA 没有覆盖这次指出的 6 个边界，不代表完整流程通过。

staging 共享模块只补入已审查的 `redesign/adminContentImages.js`，静态白名单只增加 `/styles/admin-station-content.css`、`/styles/station-admin.css` 和 `/images/station-gentle/cat-mark.webp` 的 GET/HEAD。没有放开新后台页面、服务页面或整个资源目录。

完整 CI 在原 Astro 构建之后增加 staging 包生成与精确资源检查，复用该构建产物，后续静态依赖漏记会在托管流程中失败。

显式 `owner` 通过原管理 API 按编号读取歌曲、游戏或视频，校验返回的类型与编号，不能由首批候选代替。不存在、重复参数、类型歧义或读取失败时隐藏编辑器并显示错误。尚未登记网站资料的旧歌曲，只能通过精确编号匹配的原目录记录定位；分页有上限，超过上限明确停止。素材下拉会包含已定位对象，读取权利使用该对象编号。

上传页只在初始化时接收 URL 的作品预选，后续手动选择替换当前偏好。追加列表、刷新和上传后读取保留手选作品；主动清空不会被下一页恢复成 URL 的作品。改变素材用途会清除不适用的作品偏好，服务端仍核对真实草稿与所属对象。

新建类型按钮在改变当前对象或重置表单之前检查 dirty 和待核对操作，覆盖「先展开菜单、再编辑、再选类型」顺序。重新读取提供页内确认：取消保留原修改；明确丢弃后先核对原管理员，再读取当前作品的最新版本，解除暂时锁定后恢复按钮焦点。结果未知的写入仍保留原操作键并禁止通过重新读取丢弃恢复记录。

服务页仅在通过原标签白名单后同步 URL hash。内部鼠标/键盘切换不会留下旧 fragment，同页侧栏因此可切回对应面板；隐藏的旧小说发布标签仍不会启动。

新增 `scripts/test-station-admin-navigation.mjs` 的 13 项测试执行实际入口脚本的事件处理器和原内容控制器，覆盖首批之外的三类作品、未知/非法/重复 owner、身份失败、未登记旧歌曲、菜单后编辑、版本冲突取消与恢复、原操作键保护、上传分页与提交归属，以及服务页鼠标/键盘与侧栏切换。它已纳入 `test:redesign:content-admin`，由完整 CI 执行。

本机修订验证：内容后台 55 项、上传 36 项、staging 22 项通过；完整 `npm test` 通过。完整 Astro 开发构建生成的 staging 包有 8 页、40 个精确资源，生成与资源检查均通过。该构建使用空正文选项，仅作为隔离资源包验证。另行执行的 `build:station:first-launch` 不使用空正文选项，通过品牌/游戏候选构建；两者都不是部署证据。日志见 `L07-evidence/review-fixes/`。
