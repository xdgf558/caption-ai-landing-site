# L07 — 清晰编辑台与历史歌曲恢复

用户选择的是本轮最后展示的第 3 张「清晰编辑台」，不是此前首页模板的编号。选定图保存于 `L07-evidence/selected-admin-design.png`。本批沿用一任务一 PR；新界面尚未部署。

## 新后台

`/admin-v2/` 和既有 `/admin/music/content/` 共用作品工作区。左侧为站点导航，中间为歌曲、游戏和视频列表，右侧编辑资料、查看素材与权利状态。搜索、类型筛选、独立分页游标、新建、草稿、预检、发布、下架和版本回退沿用既有内容控制器、原操作键、编辑版本与服务器核权。

`/admin/music/media/` 和 `/admin/music/` 进入同一壳。素材导航携带作品编号和用途；只有已读取且匹配的草稿可预选，找不到时保持空选择，不代选另一作品。完整音频、试听、封面和歌词继续使用原音乐工作区，深链接直接打开素材标签。上传记录区分技术校验与权利登记。图中的 500 MB 与混合格式限制没有写入产品。

原账号、订单、权益、游戏商品和通用审计工具移至 `/admin-v2/services/`，接口与控制器保留。小说、文章、导入、简报、阅读统计、旧评论与反馈编辑器保留为隐藏且 inert 的兼容结构，入口不展示，启动不读取旧内容列表或收费默认值；服务标签有显式白名单。没有删除存量数据或改账号、订单、存档接口。

列表的素材状态是当前关联记录的提示，不是 R2 现场验证。新图片查看路径仅接受已验证的海报和游戏截图，每次经现有 Access 与内容开关检查，核对对象身份后私密流式返回；它不提供音频、视频或公开授权。封面仍通过原管理资源接口。错误类型的资源不会被当作缩略图自动下载。

定时、Campaign 与报表保持原开关。报表入口在未启用时显示关闭状态。修复权利/平台视图没有 jobs、revisions 数组时的控制台错误；空操作说明会在解除临时锁定后取得焦点。手机导航关闭时不可获得焦点，打开后保留焦点范围，Escape 可退出。

## 已完成的生产歌曲恢复

用户明确要求重新发布此前已上架的歌曲。只恢复公开封存的 11 首，排除已封存且无发布指针的 `deng-hai-liang-zhe`。操作通过已登录的生产后台执行，没有用控制面 SQL 写内容，也没有伪造 Access。

22 份原封面/歌词登记以用户要求复用既有作品素材为依据，不构成独立的第三方许可审计。权利保存审计为 23 次，其中同一封面相同登记保存了两次；数据库仍为 22 份登记。正式发布审计为 11 次，每首网站修订 1 各公开一次，编辑版本 2，草稿指针为空。

12 个旧歌曲条目及其当前封存资料、引用、访问策略保持一致；35 个旧音乐资产逐字段一致。旧修订核对数量为 49，没有将数量核对称作所有历史修订的逐行比对。首页配置未改，推广、平台链接、视频记录仍为 0；试听关闭。没有新增歌曲、上传生产对象或删除原文件。

生产活动版本仍为 `1f3fb556-0b91-4946-b524-0ebe83223619`，100%；绑定与原版本一致，MUSIC_DB 账本 18 份。新后台代码尚未进入生产。审计复核和匿名 HTTP 的完成时间分别为证据 JSON 中的 UTC 时间，新加坡时间为 UTC+8。

## 验证

- 最终后台、素材、原音乐客户端回归：85 项通过，见 `L07-evidence/admin-regression-final.log`。
- 16 份既有回归脚本通过；相关源码检查转向保留的服务文件，并不意味着旧发布界面重新启用。
- `npm run build:station:first-launch` 通过；未使用空正文环境选项，兼容清单保留。该构建是候选包，不是部署证据。
- 本机浏览器验证搜索、筛选、空态、未保存保护、操作说明、保存、权利门控、预检和公开；合成夹具从草稿 2 到公开 2。游戏截图上传、预选所属作品和技术就绪记录通过。手机 390 CSS 像素与菜单/焦点检查通过；最终页面控制台无错误。
- 生产 80 项匿名 HTTP 检查通过：四语言目录各显示 11 首，11 个简中详情、22 个受控封面/歌词 HEAD、11 次原免费规则握手及各 128 字节 MP3 Range。没有登录读者或创建真实订单。首页音乐为空，四个旧入口 410，排除歌曲详情 404。`scripts/verify-station-republished-http.mjs` 提供手动只读复算入口，不由 CI/Worker 调用。

公共证据是筛选后的结果、截图和日志。原始版本绑定、SQL 行、授权依据和生产管理截图保存在本机私有发布目录，未提交。

视觉 QA 见仓库根 `design-qa.md`。合成夹具和视口检查不代替真机、VoiceOver、真实订单、云冲突或长期监控；已有首页/歌曲 LCP、原生配置和游戏并发等边界没有在本批解决。整体上线就绪结论不因本批改成通过。

合并本 PR 只接收候选代码与操作证据，不执行远程迁移、改变生产开关、部署新界面或重新打开旧公开内容。
