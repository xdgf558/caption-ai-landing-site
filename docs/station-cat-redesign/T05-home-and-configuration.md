# T05 首页与首页配置

本批实现按有效配置显示的个人品牌首页，继续使用用户选定的“温柔小站”视觉和首页、音乐、游戏、会员、关于五项导航。首页、素材状态与作品直达路径在独立 Astro 夹具中可审阅，生产页面尚未挂载新首页。实际主推、发行链接、试听开关和视频仍“稍后确定”，默认配置保持草稿、空引用，不替用户选择《晚一点告白》或《原来已经这么远》。

## 配置与公开投影

文件配置位于 `src/data/station-home.js`，沿用现有站点代码中的文件配置方式。默认 `id` 为 `ca710000-0000-4000-8000-000000000001`，`revision=1`、`publishedRevision=null`、`status=draft`、`publishedAt=null`，所有引用为空。T16 提供现有后台编辑器；本批未创建另一套后台、账号或可写 API。该文件仅定义前端输入合同，尚未接入生产首页。

| 输入 | 本批要求与输出 |
| --- | --- |
| HomeConfig | 稳定 UUID；整数 revision；公开快照须 published 且时间不在未来，publishedRevision 与该快照 revision 一致。未发布或版本不一致返回空首页。 |
| 主推 | featuredTrackId 精确引用公开 Track，且该曲 PromotionTrackConfig 已发布、enabled=true、有正整数 revision。无默认“最新免费”回退。 |
| Track | 有稳定 ID/有效 slug、原始语言标题、作者及就绪公开且权利已登记的所属封面。可选简介为空时允许展示；缺翻译回到原始语言，ID 不变。 |
| 精选 | selectedTrackIds 去重，排除当前主推，过滤失效对象，最多显示三首。 |
| PlatformLink | 由推广配置选中、同一首曲、已知 provider、live 状态、核验时间有效且不在未来，URL 格式合格后才输出。网站作品公开不推导平台发行。 |
| 推广试听 | previewEnabled=true 且所属独立 preview 类型资源标为 ready/public/rightsConfirmed、时长为有限正数，才输出时长和作品页 #preview 入口。首页不输出音频 URL，也不额外定义规范未要求的时长上限。 |
| 短视频 | 同时被首页和该曲推广配置选中，关联当前主推公开歌曲，素材类型 short_video，海报和视频资源所属正确、ready/public/rightsConfirmed，发布时间有效，最多四张。无有效视频时整个区块隐藏。 |
| 主推游戏 | featuredGameId 精确引用公开对象，名称/slug有效且所属 game_screenshot 资源就绪、公开、权利已登记。介绍 slug 不得使用运行目录 `cat-life`；无有效引用时显示空态。只进入介绍地址，不启动运行页。 |
| 动态 | 最多三条显式选中的公开记录；音乐/游戏目标须继续有效；生活记录需要所属公开封面，沿用 `/about/`，不新增文章系统。 |

`src/redesign/home.js` 的 `buildHomeView()` 是前端白名单投影，不是认证、权限或 D1 查询层。输出只含呈现需要的字段、公开图片及作品导航，丢弃原记录中的完整音频地址、存储键、权益等附加属性。重复 ID 的记录整体视为歧义，避免依赖返回顺序。资源撤销、父歌曲下架、平台停止发行后，下次投影会去掉对应引用；这不证明生产缓存已清除。

URL 检查拒绝非 HTTPS 外站地址、凭证、端口、fragment、IP/本地/保留域名和明显 token/签名参数；本站图片限公开图片或封面接口格式。它不联网、不下载，也不能证明歌曲真实发行或图片资源可访问。`verifiedAt`、发布状态和权利标记必须由受信任的服务端输入提供，T07 负责公开查询和实际资源/权限校验。仅凭 preview 类型和元数据不能证明文件确实独立剪辑，T07/T16 发布校验仍须验证资源；本批不声称游客实际试听通过。

后续编辑器必须把编辑草稿与已发布快照分开保存，例如 revision 2 草稿不能覆盖仍在使用的 revision 1 发布快照。本函数只消费一个已发布快照，不负责保存、并发发布、回退或缓存。T06 将这些前端逻辑字段映射到既有兼容模型，不能据此认为 D1 已新增字段或生产 schema 到位。

## 页面与状态

首屏保留品牌说明、音乐/游戏两条入口；有有效主推时直接进入对应作品，没有时进入音乐或游戏目录。主推歌曲卡片显示作者、真实平台入口与条件试听入口，精选/短视频根据有效引用显示，游戏和页脚复用 T04 壳。四语言文案与窄屏纵向布局已接入组件；不加载或预加载完整音乐、视频、iframe。

示例 URL 要同时满足 `fixture=true` 和配置 `environment=fixture` 两个条件才可使用。普通消费者拒绝带 fixture 标记的配置，不能误用本地示例。夹具平台按钮仅进入 `/__home-fixture/platform/:provider/` 说明页，标注“示例入口”，没有填入虚构的外站发行链接。图中的愿望清单保留本次预览反馈，明确未同步账号，刷新清除；没有增加收藏数据能力。

| 本地状态 | 地址（繁中，其余语言加现有前缀） | 行为 |
| --- | --- | --- |
| 素材待定 | `/` 或 `/home-preview/pending/` | 使用实际空草稿；音乐、游戏空态，没有假主推、平台、视频或动态。 |
| 完整素材示例 | `/home-preview/complete/` | 一首合成主推、三首精选、四张视频、三条本地平台入口、一款游戏、三条动态。试听开关关闭。 |
| 缺视频 | `/home-preview/no-video/` | 合成 Clip 保持草稿，视频区块隐藏，其余内容保留。 |
| 缺平台入口 | `/home-preview/no-platform/` | 平台处于待发行，显示“正式平台入口稍后公开”，没有平台按钮。 |
| 试听入口开启 | `/home-preview/preview-enabled/` | 独立 preview 元数据合格，显示进入 #preview 的按钮；没有真实音频。 |
| 撤销素材 | `/home-preview/revoked/` | 停用一个平台，撤销一条视频及另一条海报，剩两条平台、三张视频。 |

`HomeDestinationFixture.astro` 仅为本地按钮验收提供对应标题与 #preview/#clip 目标。精选曲目的说明页不借用主推视频；游戏说明页不读取存档或启动真实运行。它们不是 T08 的正式单曲页、T09–T11 的播放器或 T12 的游戏介绍完成证据。

重现：在仓库运行 `npm ci`、`npm run preview:redesign`，访问 `http://127.0.0.1:4204/`。预览独立构建至 `.generated/station-redesign-preview`，服务器仅监听 loopback、接受 GET/HEAD，输出 noindex；不能将该目录发布为生产包。`/visual/` 可继续检查 T04 原视觉样例。默认首页没有正式内容；查看完整视觉效果应选择上表的完整素材示例。
