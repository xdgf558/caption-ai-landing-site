# T16 后台设计 QA

最终界面没有遗留的 P0/P1/P2 视觉阻断。此次使用 Product Design 的既有界面与设计 QA 流程，目标为继续原音乐后台的绿色工作区；这是新增管理模块，不是重做用户已选定的公共首页。

## 对比依据与尺寸

原界面：`../T15/source-existing-music-assets.png`，1265 px 宽。实现：`promotion-reference-width.png`，在 1280 CSS px 视口、15 px 竖滚动条下捕获 1265 px 内容宽，与原图同时打开比较。另保存 1440 的完整界面，以及 320/390/768/1024 的实际 DOM 几何与截图。图片均为 IAB 浏览器截图，不经重绘或贴图；截图不含浏览器边框。两个工作区的内容类型与页高不同，比较相同的导航、标题、列表、标签和操作控件，不比较无对应意义的整页高度。

初轮参考宽度不一致已重拍；最初隐藏标签未收到 viewport 变化，未将它当成响应式证据。正式五宽度检查都记录 `window.innerWidth` 和内容实际宽度，scrollWidth 等于 clientWidth。`admin-desktop.png` 是初轮默认 1280 的草稿观察，最终以 `admin-final.png` 与 `promotion-1440.png` 为准。

## 已核对的五个方面

- 字体：直接复用原 `admin-music.css` 的 system-ui、-apple-system、PingFang SC 字体栈，正文 14 px/1.6、主标题 26 px。副标题在新编辑区为 22 px，以容纳明确的歌曲名与操作上下文；提示 12 px、徽标 11 px 沿用原后台。中英文字、长标题和原始编号均换行，不使用营销字体或自行仿字。
- 间距：桌面为 260 px 列表、24 px 间距与 28 px 编辑内边距；1000 以下侧栏 220 px，760 以下改为单列。增加带边框的列表容器用于八模块切换，是新增功能的布局选择；输入控件仍是原 4/5 px 圆角。320 下表单、按钮、下拉、长操作标题均可完整横向显示。
- 色彩：复用原背景 `#f6f8f7`、文字 `#25342e`、主要按钮 `#326451`、边框 `#becbc4`、提示与状态样式。新增选中模块/列表是浅绿。错误提示已修正为原红色 `#a2353c` 并滚动到可见位置，保留 role=status；错误字段显示中文名称。
- 图像：此工作区没有新增插画或作品假封面。标准界面图标来自项目已有 Lucide。与原后台相比，品牌图片改为返回音乐工作区的原有导航样式，符合 T15 独立素材页面模式；不是以代码仿造用户首页猫咪插画。
- 文案：当前草稿、公开版本、编辑版本、权限角色分开显示。下架后标为“历史公开”，不将封存历史当成仍有效的推广。试听和平台没有真实发行默认值，Campaign 明示后续任务。预览仅称“资料预览”，不宣称真实媒体或生产页面已验证。

## 功能状态与修正

浏览器实际走通歌曲草稿保存（含多行说明）、缺少权利拒绝、合成夹具权利登记、资源核对/窄屏资料预览、公开与再次修订、从版本 2 恢复成新公开版本 4、推广公开与停止、审计记录单条选择。

已修复推广标题缺少所属歌曲、旧空标题误称首页配置、平台/权利搜索未带查询、跨模块遗留反馈、审计列表点击隐藏内容、错误字段暴露内部标识和错误不可见。历史版本和同歌曲视频/资源所属对象选择可继续读取，避免只提供最近一页。

模块导航在 390 视口下全部 44 px 高；输入、主要操作和摘要有 44 px 最低可点击高度。沿用原 focus-visible 金色描边与语义标签。浏览器视口模拟未覆盖真机、完整键盘路径或 VoiceOver，不将辅助技术验收标为通过。

## 接受的范围与剩余缺口

资料预览不包含生产页布局或媒体播放；合成权利依据不代表实际授权。实际上线链接仍待用户，未点击原平台网址。权利表单有单行依据格式约束。每个 owner 素材表单累积最多 1,000 份，超过范围需使用 API 的 kind 筛选；没有新增删除/配额释放功能。

未知回执、身份切换和 sessionStorage 故障由控制器专项合成测试核对，没有在浏览器注入断网。生产资源、正式迁移、最大媒体、云冲突、iOS/Android/内置浏览器和 VoiceOver 仍须后续验收。
