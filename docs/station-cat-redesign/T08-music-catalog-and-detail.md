# T08 音乐目录与单曲页

基线为 T07 实际合并提交 `828d5a9d345e171dd2d28b159943c09beeaa63c4`。T07 的用户审查头 `0b9d7b6` 经完整托管 CI 通过后合并；这不能替代 T08 当前头 CI。本任务继续一任务一 PR，停在 T08 待审，不进入 T09。

本批实现音乐目录、单曲展示、直接分享落地和必要的显式播放入口。视觉使用用户“温柔小站”图及已审查的五项导航，并调用 Product Design image-to-code/design-qa 流程。没有替用户选定主推、发行链接、试听开关或视频；所有本地作品、权利记录与音乐都是夹具。

## 正式路由与默认关闭态

HTML 路由新增独立 `STATION_MUSIC_PAGES_ENABLED` 开关，生产配置没有设置它，也没有设置 `STATION_CONTENT_PUBLIC_ENABLED`。两项开关均开启，且实际 MUSIC_DB/R2 就绪时，新路由才调用 T07 查询并渲染；本批没有远程迁移、启用开关或生产部署。

| 地址 | 开关开启并通过校验后的行为 | 默认关闭时 |
| --- | --- | --- |
| 四语言 `/music/` 根页面 | 服务端生成目录；主推和精选仅来自已发布首页配置 | 交回旧音乐 HTML 处理器 |
| `/{locale}/music/tracks/:slug/` | 仅当前已发布实体可被新处理器认领；alias/无斜线等规范化使用临时 302；查无映射返回 null 交回旧处理器 | 交回旧音乐 HTML 处理器 |
| 根页唯一合法 `?track=UUID` | 先读取实际发布实体，再以详情查询核对 canonical；匹配成功才 302 | 原处理器 |
| 旧单层 `/music/:slug/` | T07 可查到当前 canonical 时 302 | 原处理器 |
| `?collection=`、未映射 UUID、未知后代 | 原处理器；不在本批推断对应单曲、关闭或迁移 | 原处理器 |
| `/music/site-shell/:locale/` 及语言/编码变体 | 内部静态壳，对外请求 404 | 同样 404 |

繁中 canonical 仍为 `/music/`，其余为 `/zh-hans/music/`、`/en/music/`、`/ja/music/`。`/zh-hant/music/` 是规范化别名。旧后代路径的完整生产实体、动态 D1 slug、外部推广链接及客户端清单仍须 T20 实际核对；本批只解析当前可证明的映射。AASA 没有扩展到单曲路由。关于仍只有原 `/about/`，游戏介绍仍待 T12，`/games/cat-life/` 没有被占用或重定向为介绍。

新处理器默认关闭时，对目录、旧分享和单曲路径统一返回 null，不读取绑定或先验证查询/方法；最终状态仍由旧处理器决定，不意味着旧处理器已有详情页。内部静态壳继续保持外部 404。页面开关开启但查询开关关闭，仍按配置不可用返回 503。

被新处理器认领的页面仅 GET/HEAD，其他方法 405；HEAD 经过同样查询/校验但无正文。响应 `private, no-store`、`noindex,nofollow`，没有新增 sitemap 地址。loopback 预览的 canonical、OG 和 hreflang 使用实际本机来源；公开主机仍固定正式域名，不相信转发头。两者均不能作为正式索引验收。T20 再决定正式索引和关闭被替代入口。规范化仅保留合法且唯一的目录参数与四个 UTM 参数，去掉 token 等未知参数；UTM 未被采集，也不是访问凭证。

内部四语言 Astro 壳被普通构建打包，Worker 以 ASSETS 读取指定壳并通过 HTMLRewriter 写入静态作品内容、title/description/canonical/OG/hreflang 和受限 JSON。查询成功不依赖浏览器执行脚本，主要作品信息和搜索/下一页链接无 JavaScript 也可访问。壳不含示例作品或音频源；缺少绑定、schema 或壳时拒绝并提供重试。生产 `run_worker_first` 已覆盖音乐、语言及编码路径，本批未改变该配置。

## 目录排序和分页

T07 API `/tracks` 增加可选 `sort=default|release`，保留没有 sort 的旧调用：仍按网站发布时间排序，使用 v1 时间/ID 游标。新网站显式请求 sort，单页 20；API 上限仍为 50，SQL 最多读取 limit+1。搜索使用请求语言标题、原语言回退及艺名；不把旧浏览器收藏、全量媒体或云资料库当搜索数据库。

`default` 先按当前封存且启用推广的 sort_order 升序，再按网站发布时间降序、ID 升序；没有有效推广的作品排在后面。`release` 使用最早的全局外部发行时间，按新到旧排序，未知日期放后，ID 用于稳定的同值排序。该日期要求平台记录 live、核验时间及发行时间是合法的非未来整数；不从网站 published_at、旧精选或文件时间推断发行。

新增 DTO `catalogReleasedAt` 表示以上**运营登记的全局排序日期**，不等于当前访客适用的按钮。地区和 HTTPS/主机校验继续决定 `platforms` 与原 `releasedAt`。排序不发外网核验请求，不证明平台链接真实可访问、正式发行、素材版权或生产配置。运营登记不能代替 T10/T16/T20 的核验。

v2 游标携带 sort/group/order/time/id，scope 是语言、搜索词和排序的 SHA-256；错误范围、跨语言/搜索/排序复用或未知字段返回 400。它不是签名或权限凭证，只用于公开有界查询。按源页最后扫描行推进，过滤后空 items 仍可能有 nextCursor。排序读取实时记录，并非跨请求快照；运营修改可能移动记录，前端追加时按 ID 去重。每次点击只再取一页，不自动扫描全部目录。

未配置主推不会回退“最新免费”；有效精选可以独立展示，缺封面则折叠图片位。真正空目录显示准备状态，空搜索提供清除入口，错误提供重试。浏览器搜索/排序只替换结果区域，取消过期请求并校验响应；返回上一条历史不再创建新的历史条目。GET 表单和下一页地址仍可独立使用。

## 单曲展示、收藏和播放器入口

单曲页展示封面、标题、艺名、简介、平台按钮、可用短视频/MV 海报或核验过的原发布入口、按需歌词、纯文本故事和最多三首关联作品。没有对应资源的块折叠，不挂载空 video/iframe 或虚构平台按钮。视频播放器、字幕及曝光采集仍属 T11；T08 海报不是视频播放验收。

HTML、属性和 JSON 分别转义，用户或运营内容不会作为 HTML 执行。歌词通过受控 assets 路径在展开后才请求，最大 128 KiB，沿用现有歌词解析器，以 textContent 显示；失败可重试。公开 JSON、静态壳和歌词读取均有字节上限。请求时限只放弃等待，不取消已经发出的 D1 查询。

收藏复用 `createMusicLocalData()` 的真实 `stationcat.music.v2` 键，刷新保留，并明示“保存在此设备”。不可读/损坏存储保持原文，使用临时收藏；不是账号同步或原生 `/api/mobile/v1/me/music/*` 的替代。现有站点没有可复用的音乐评分提交系统，本批没有新增评分或伪成功交互。

页面只挂载一个 `audio preload=none`，无 src/autoplay。推广试听使用当前网站版本 v 和独立推广版本 p，用户点击后同步调用旧播放器核心的 play；媒体端每次重新校验独立资源、权利、版本和推广开关。停止推广不因为浏览器已有 DTO 而继续授权下一次请求。实际已经下载的浏览器缓冲不会由服务端追溯清除；T09 继续处理播放生命周期和失效状态。

新增公开 `fullPlayback.playbackPath` **仅提示私有权限握手入口**，并明确带 `requiresAccessCheck: true`，不返回音频地址，也不授予免费或 VIP。四语言入口先显示“确认完整收听权限”和待确认说明；只有私有握手成功后才显示准备播放。拒绝、关闭播放器或恢复页面时回到待确认态。提示要求旧当前发布指针与网站引用相符；媒体可用性及最终权限仍由 T07 的旧 `resolveMusicAccess()`、会话、有限期会员和 R2 检查决定。`site_audio_mode` 没有被用作放行条件。

完整音频先由一次点击请求私有 playback，返回严格匹配的 trackId/revision/variant/受控 audioPath 后显示“已准备好，点击播放”；再次主动点击才赋 src 并 play，保留浏览器用户激活。失败显示真实提示及现有会员入口，未授权不查完整 R2。关闭播放器卸载源并清除准备状态，不留“已准备好但无法播放”的按钮。旧播放器默认 UUID 地址不变，新增的同步 sourceFor 仅供该页面受控适配器使用。

跨页面播放器、队列恢复、完整播放器体验及新播放事件仍属 T09/T18。旧 qualified_play/90% 完成规则没有改，新有效试听的“前台实际累计 10 秒或结束、同一 playback_id 一次”未在 T08 标为已验收。没有新 station_analytics_events 写入、保留期或销户执行。

## 本地预览、证据及边界

25 条合成网站作品用于验证有限分页，其中主推和发行名称是视觉示例。封面沿用 T04 插画；试听/完整 MP3 使用仓库 FFmpeg 合成音及 manifest SHA-256，歌词为原创测试文案；不是实际歌单或版权证明。视频仍是 100 字节的 metadata/权限夹具，仅海报是有效图像，不能宣称视频可播放。真实主推、平台、试听设置和 MV 均待用户确定。
