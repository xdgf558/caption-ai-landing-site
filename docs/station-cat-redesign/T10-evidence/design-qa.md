## 视口和捕获边界

`viewport-measurements.json` 记录 CSS 视口 1440×900、768×900、390×844、375×844、320×740，DPR 1。clientWidth/documentWidth/bodyWidth 分别为 1425、753、375、360、305，三者相等，无水平溢出。复制按钮桌面为 64×44、手机为 54×44，折叠标题高 44px。

完整截图 `platform-live-1440.jpg` 为 1425×1244，390 为 375×1572，320 为 305×1742。完整页面捕获会将固定底部导航放在中段，也会捕获 DOM 实际 top=-100 的跳至主要内容链接；这些是截图合成现象，不用它判断实际固定位置。真实视口图 `platform-copy-viewport-390.jpg` 为 375×812，原生 IAB 捕获少于 CSS 高度 844，仍能看见复制区及底部导航；不把原生捕获当作完整 1:1 手机屏幕。桌面最终对照使用返回 scrollY=0 后的 `platform-collapsed-1440.jpg`；早期缩放原生图和滚动未归零截图不作最终对照。

`image-metadata.json` 保存各文件真实尺寸；所有组合均等比例 contain。首次完整/聚焦构图因页面滚动造成顶部裁切，已归零后重新捕获并重新组合、查看。这个修正只处理证据对齐，没有更改 UI 源码，也不是设计修复迭代；本次正确对照未发现 P0/P1/P2。
