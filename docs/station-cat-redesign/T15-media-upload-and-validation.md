## 上传和恢复合同

| 请求 | 用途 |
| --- | --- |
| GET/HEAD `/status` | 当前管理员、共享配额、支持的技术限制与可上传状态 |
| GET/HEAD `/owners?kind=…&cursor=…` | 当前可编辑的视频/游戏草稿；30 条一页，按时间与 UUID 处理同时间记录 |
| GET/HEAD `/` | 当前管理员上传记录；20 条一页，单次关联查询 |
| POST `/` | 以 ownerId、kind、format、byteSize、sha256 预留版本；不接受任意对象路径 |
| GET/HEAD `/:id` | 查询安全 DTO、阶段、错误和恢复动作 |
| PUT `/:id/body` | 唯一写入者发送实际文件流，不能重写已占用版本 |
| POST `/:id/complete` | 读取实际对象、测量并原子确认，同一或不同幂等键重复确认仍只有一份资产 |

服务端保存 `reserved → uploading → uploaded → validating → completed`，另有 rejected/expired；DTO 映射为 uploading/validating/ready/failed，并区分可以继续查询的未确认结果和需要另建版本的确定失败。PUT 成功不是 ready，确认成功也不是版权审核或公开发布。

预留、唯一写入者占用、最终确认分别使用幂等操作。每个对象为 `station/media/{kind}/{ownerUUID}/{assetUUID}.{format}`。R2 PUT 使用固定声明长度、增量计数、声明 SHA-256 和仅创建条件；同一版本不能重新 PUT。浏览器先保留操作键再发请求；结果未知时查询原记录，而不是再发一份文件。客户端日志存在当前标签页、当前管理员的 sessionStorage 中，仅有命令、阶段和结果，没有 File、文件内容、JWT 或音频/视频地址。存储不可读时不开始新上传；刷新不自动发送文件。

确认使用 R2 HEAD 和匹配 etag 的 GET，核对对象身份、自定义归属元数据、MIME、完整范围、实际总字节与全文件 SHA-256。上传后未收到响应，也能对原对象重新确认。validation 状态在读取前提交；Worker 中断或短暂存储故障保留可重试状态。不同确认请求争用同一记录时，最终只有一笔完成审计。查询超时会停止等待并关闭已取得或迟到的对象流，不能取消已经发出的 R2 HEAD/GET；同步解析的 CPU 时间也不由 JavaScript 计时器抢占。

会话预留 24 小时，同一管理员最多十个存活新素材会话。文件传输窗口为 120 秒，确认的对象读取窗口最长 30 秒。这些限制是应用侧上限，不保证 Cloudflare 账户请求体限制、网络、CPU 配额或真实最大文件能通过；生产启用前必须核对所用套餐并实测。没有新增 multipart、转码服务或后台续传；中断后先核对原对象，确定失败再另建版本。

## 技术校验范围

短片/MV 接受自包含、非分段 MP4，单路 avc1 H.264 8-bit 4:2:0，可附一路 mp4a AAC-LC；最大 256 MiB、30 分钟、7680 像素边长。fast-start 与尾部 moov 均支持，moov 最多 2 MiB、4096 个容器盒、每轨最多 200000 个样本。WebM、HEVC、AV1、fragmented MP4、外部数据引用和不支持的轨道/矩阵/像素比例明确拒绝。以前已发布的 WebM 读取路径不变，这只限制本批新上传。

视频时长由 mvhd/mdhd/tkhd、编辑列表与 stts 的一致性核对；AAC 允许一个 priming frame。ctts 重排序偏移最多一秒，并核对呈现时间范围；样本数量、stsc 映射、stco/co64 偏移必须完整、位于 mdat 内且互不重叠。尺寸从 H.264 SPS 解析，并与样本入口、tkhd 对照；支持正常横竖屏的四种旋转。最终测量标为 `mp4-container-sps-v1`。

海报/游戏截图接受静态 JPEG、PNG、WebP，最大 10 MiB、4096×4096，复用现有有界图片结构检查。扩展名/MIME 声明不能代替实际文件结构。音频复用原 MP3 逐帧测量及本机 WAV 转码；原完整音频和独立试听必须是不同资产，试听继续绑定已验证原曲与截取区间，不产生新的会员授权。

此校验证明支持格式的结构、测量和完整传输，**没有逐帧解码视频/图片的压缩载荷，也不是病毒扫描、播放质量或使用权审核**。mdat 载荷不解码，因此有效容器内的坏帧、黑屏、静音等仍需播放复审。全文件 SHA 与客户端声明一致不能单独证明原文件可播放。合成插画/正弦音夹具不代表真实歌曲、视频或版权；T16 发布前仍须真实预览、权利登记和引用核验。A04/A15/A18 仅按下面的隔离技术范围取得证据，不标记完整生产验收。

会话身份、声明长度/SHA、归属与写入者不可改换；终态不可重开或删除。0012 的网站素材保留与已封存引用保护继续有效；新完成状态必须对应同一尺寸/字节/SHA 的 validated 资产。测试包含已封存历史引用，未物理删除任何文件。准备素材不自动绑定草稿、不写 station_asset_rights、不发布作品、不启用推广，也不改原 `site_audio_mode` 或会员校验。
