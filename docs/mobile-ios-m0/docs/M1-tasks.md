# M1 开发任务安排（待启动）

目标：建立可启动三标签SwiftUI骨架、冻结可测试API契约和CI。输入为主规格v1.0.1及M0两份ADR、基线差异/风险。当前没有执行M1或创建远端任务。

| 任务 | 具体交付 | 验收及依赖 |
|---|---|---|
| M1-01 基线封存 | 网站集成分支来源清单；保留生产9文件差异；修正封面展示版测试与海报原图双重断言 | 原有认证/媒体/目录回归全绿；不得直接用main覆盖部署来源。属于后续集成前置，不改支付。 |
| M1-02 正式本地工程 | 独立iOS工程、iOS18 target、Dev/Mock/Staging/Production配置、版本锁定、正确模拟器签名和Keychain服务名 | 三标签冷启动不播放；默认Mock，生产写接口不可误调用。首先解决M0的errSecMissingEntitlement并复测单item存储。无远端创建/签名账号变更。 |
| M1-03 契约 | 完整OpenAPI路径/认证/DTO/错误/时间单位/分页；四语错误键；虚构fixtures | schema验证；未知authMode与未知权益拒绝；receipt32字节编码与hash一致；旧路径不改语义。 |
| M1-04 网络和作用域 | APIClient、依赖注入、取消与操作序号、只读Mock；账号/游客缓存隔离接口 | 迟到搜索/登录结果不能覆盖新scope；不把503变成会员过期；无硬编码token/支付价格。 |
| M1-05 播放/认证接口壳 | 唯一服务所有权、连续时钟抽象、loader/Keychain协议、状态机接口 | M0模型转为Swift单测；页面切换不重建播放器。未实现服务显式标注，不复制探针的固定凭据或HTTP例外。 |
| M1-06 设计与可访问性 | 深色猫咪设计令牌，发现/曲库/我的空态、加载态和错误态；四语、动态字体/VoiceOver | 原生布局与44pt目标；减少动态效果；不出现未上线购买、离线或假曲库数量。 |
| M1-07 CI与交付说明 | 编译、Swift测试、OpenAPI/fixtures验证、敏感数据扫描、README与命令 | 未配置设备签名显示未验证；不自动部署/TestFlight；可复现报告，不以Mock冒充实服务。 |

建议顺序：01/02明确来源与工具链 → 03冻结契约 → 04/05基础服务 → 06界面 → 07集中验收。单阶段提交审查，不把M2认证、M3服务端或StoreKit购买混入M1。
