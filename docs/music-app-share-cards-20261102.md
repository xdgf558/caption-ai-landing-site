# Station Cat Music: share links and cards

This change prepares public song and album share pages and their portrait previews for the iOS app. It does not deploy or enable them. The user selects the link sharing action; no accounts, credentials or campaign attribution are included.

- Paths are `/music/share/tracks/{canonical-slug}/` and `/music/share/albums/{published-album-slug}/`, with optional `?locale=zh-Hans|zh-Hant|en|ja`. The default locale is `zh-Hans`.
- The page returns Open Graph and X/Twitter tags and a visible fixed App Store link. The `card.png` child generates a 1200 × 1500 preview from the current published work title, its published summary, and its independently owned cover when available. Long summaries are visibly truncated with an ellipsis in the preview; the landing page and metadata use the complete summary. The album `cover.png` child is a publication-checked PNG thumbnail for the iOS preview, preserving transparency and bounded to 512 pixels on the long edge and 2 MiB; no cover results in 404.
- No new player, third-party platform link, audio data, account information or fabricated description is exposed. Every request checks publication; the album route checks the published album and its independent cover. Responses use `private, no-store` and recheck after withdrawal, though third-party platforms may retain cached previews outside our control.
- `STATION_MUSIC_SHARE_ENABLED` must be explicitly set to the string `true`, and `STATION_CONTENT_PUBLIC_ENABLED` must already be enabled. The new flag is absent by default. Existing `MUSIC_DB`, `MUSIC_BUCKET`, `ASSETS`, rate-limit secret, and bundled font/icon assets must be available. Rendering and artwork share the existing share-specific rate limit and have bounded reads. No migration is added.
- The page intentionally does not automatically redirect. This preserves its metadata for social crawlers and leaves a download action available when an in-app browser blocks an App Store launch. A photo alone is not a clickable URL. Actual X and WeChat link-card behavior, crop, and store opening must be tested on those platforms and cannot be guaranteed by this code.
- Before enabling, independently validate the current production Worker and assets, including the later L35 cover variants, and build from complete production content. A build using empty local novel folders is only a compile check and must never be deployed.
