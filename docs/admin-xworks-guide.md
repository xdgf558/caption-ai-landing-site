# How to add an X Work

1. Publish a post or video on X.
2. Copy the original X post URL.
3. Open `/admin/`.
4. Paste your GitHub fine-grained token.
5. Open the `X Works` tab.
6. Click `New X Work`.
7. Fill in title, description, X URL, type, tags, language, featured, status, sort order, and published time.
8. Use `Preview embed` to check the X embed.
9. Set status to `published` when ready.
10. Save.
11. Wait for Cloudflare Pages to redeploy.
12. Check `/` and `/works/`.

## Token Permission

Use a GitHub fine-grained token with access to this repository only.
Required permission: Contents: Read and write.
Do not store or share the token.

## Content Rules

Only paste the original X or Twitter post URL, such as `https://x.com/username/status/1234567890`.
Do not paste iframe code, script code, embed HTML, or downloaded video URLs.
